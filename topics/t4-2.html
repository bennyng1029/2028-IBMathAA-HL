Topic 4.2 · SL 4.5–4.9, 4.11–4.12 + AHL 4.13–4.14

Probability, distributions, Bayes and continuous RVs

Guiding questionHow do we update probabilities when new evidence arrives, and how do discrete sums become continuous integrals when outcomes vary smoothly?

What you need to be able to do

  • Use Venn diagrams, tree diagrams, and the addition rule P(A ∪ B) = P(A) + P(B) - P(A ∩ B); distinguish mutually exclusive (P(A ∩ B) = 0) from independent (P(A ∩ B) = P(A)P(B)) events, and evaluate conditional probabilities P(A | B).
  • Verify discrete probability distributions (Σ P(X = x) = 1), calculate expected value E(X) = Σ x P(X = x), and determine whether a game is fair (E(gain) = 0).
  • Model fixed-trial experiments with the Binomial distribution X ~ B(n, p), compute probabilities by formula and GDC, and solve minimum-trial problems 1 - (1 - p)^n > c.
  • Compute Normal probabilities and inverse Normal quantiles, standardize to Z = (X - μ)/σ ~ N(0, 1) to find unknown μ and σ, and link Normal probabilities into Binomial or conditional models.
  • Apply Bayes' theorem P(B_i | A) for up to three partitioning events B_1, B_2, B_3 to reverse conditional probabilities.
  • Compute discrete variance Var(X) = E(X^2) - [E(X)]^2, apply linear transformations E(aX + b) and Var(aX + b) = a^2 Var(X), and find the mode, median, mean, and variance of a continuous random variable from its PDF f(x).

Question decoder: spotting which probability tool to use

Probability exam questions hide their mathematical structure inside everyday stories. Scan the wording for these trigger phrases before writing your first line of working.

Question decoder — Probability, distributions, Bayes' theorem and continuous RVs
What the exam question says What it means (formula & setup) Paper 1 (No GDC) vs Paper 2 (GDC)
“Events A and B are mutually exclusive” vs “independent” Mutually exclusive: cannot happen together, so P(A ∩ B) = 0.
Independent: one does not affect the other, so P(A ∩ B) = P(A)P(B) (and P(A | B) = P(A)).		 Substitute P(A ∩ B) = 0 or P(A)P(B) into P(A ∪ B) = P(A) + P(B) - P(A ∩ B). Never confuse the two!
“Given that / knowing that / among those who…” Conditional probability P(A | B) = P(A ∩ B) / P(B), where B is the known condition. Write the fraction P(A ∩ B) / P(B) explicitly—even inside a Normal or Binomial question (e.g., P(X > 15 | X > 10) = P(X > 15) / P(X > 10))!
“Stage 1 priors P(B_i) and stage 2 conditionals P(A | B_i) are given; find P(B_i | A)” Bayes' theorem (reversing the tree): divide the single desired path P(B_i)P(A | B_i) by the sum of all paths reaching A. Draw a two-stage tree diagram, multiply along each branch to A, and form P(B_i ∩ A) / P(A).
“Fixed number of n independent trials with constant success probability p” Binomial distribution X ~ B(n, p) with P(X = r) = nCr p^r (1 - p)^{n-r}, E(X) = np, Var(X) = np(1 - p). Paper 1: Use nCr p^r (1 - p)^{n-r}.
Paper 2: Watch out for binomcdf: P(X ≥ k) = 1 - P(X ≤ k - 1)!
“Find the minimum number of trials n such that P(at least one success) > 0.95” Use the complement: P(X ≥ 1) = 1 - P(X = 0) = 1 - (1 - p)^n > 0.95 ⇒ (1 - p)^n < 0.05. Solve n > ln(0.05) / ln(1 - p) (remembering ln(1 - p) < 0 flips the inequality!) or inspect a GDC table, then round up to the next integer.
“Continuous measurement X ~ N(μ, σ^2) with unknown μ or σ” Standardize to Z ~ N(0, 1) using z = (x - μ) / σ, where z = invNorm(left-tail area). Write x - μ = z σ. If both μ and σ are unknown, set up two linear equations and solve simultaneously.

What is NOT in the IB Math AA HL syllabus: The Poisson distribution, Central Limit Theorem (sample mean distribution X̄ ~ N(μ, σ^2/n)), confidence intervals, and linear combinations of two independent random variables (aX + bY) are in IB Math AI HL, not IB Math AA HL. In AA HL 4.14, linear transformations apply only to a single random variable (aX + b).

SL 4.5, 4.6, 4.11

Combined events, independence and conditional probability

For any two events A and B in a sample space U, the probability of their union (at least one occurring) and the conditional probability of A given B are connected by two fundamental identities in your Formula Booklet:

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)    |    P(A | B) = P(A ∩ B)P(B)
P(A ∪ B)
probability that A or B (or both) occurs
P(A ∩ B)
probability that both A and B occur together
P(A | B)
probability of A occurring given that B has already occurred

Never confuse Mutually Exclusive with Independent: Two events with non-zero probabilities (P(A) > 0, P(B) > 0) can never be both mutually exclusive and independent! If A and B are mutually exclusive, then P(A ∩ B) = 0. If they are independent, then P(A ∩ B) = P(A)P(B) > 0.

When solving Venn diagram problems, always fill in the intersection P(A ∩ B) first, then subtract P(A ∩ B) from P(A) and P(B) to get the crescent regions P(A ∩ B') and P(A' ∩ B).

Solving for an unknown probability using independence and conditional probability

Events A and B are independent with P(A) = 0.4 and P(A ∪ B) = 0.7.
(a) Find P(B). [3 marks]
(b) Find P(A' | B') (the probability that A does not occur given that B does not occur). [2 marks]

  1. Independence means P(A ∩ B) = 0.4 P(B).

    P(A ∪ B) = P(A) + P(B) − P(A)P(B) [M1]
    0.7 = 0.4 + P(B) − 0.4P(B) ⇒ 0.3 = 0.6P(B) ⇒ P(B) = 0.5 [A1 A1]

  2. Outside the union A ∪ B lies A′ ∩ B′, which has probability 1 − P(A ∪ B) = 0.3. (Or note that if A and B are independent, A′ and B′ are also independent!)

    P(A′ | B′) = P(A′ ∩ B′)P(B′) = 1 − 0.71 − 0.5 = 0.30.5 = 0.6 [M1 A1]

(a) P(B) = 0.5; (b) P(A′ | B′) = 0.6

Given that P(A) = 0.5, P(B) = 0.6, and P(A ∪ B) = 0.86, calculate the conditional probability P(A | B).

  1. First find P(A ∩ B) = P(A) + P(B) - P(A ∪ B).
  2. Now divide P(A ∩ B) = 0.24 by P(B) = 0.6.
P(A ∩ B) = 0.5 + 0.6 − 0.86 = 0.24
P(A | B) = 0.24 / 0.6 = 0.4
SL 4.7–4.8

Discrete random variables and the Binomial distribution

A discrete random variable X takes distinct values x_1, x_2, ... with probabilities P(X = x_i) ≥ 0 whose sum must equal 1. Its long-run average is the expected value E(X):

∑ P(X = x) = 1    |    E(X) = μ = ∑ x P(X = x)
P(X = x)
probability mass function (every probability is in [0, 1] and total sum is 1)
E(X)
expected value (mean μ); in a fair game, E(net gain) = 0

The Binomial distribution X ~ B(n, p)

When an experiment consists of n independent trials, each having only two outcomes (success with constant probability p and failure with probability q = 1 - p), the total number of successes X follows a Binomial distribution X ~ B(n, p):

P(X = r) = nCr pr(1 − p)n−r    |    E(X) = np    |    Var(X) = np(1 − p)
n, p
number of independent trials n and probability of success p on each trial
r
number of successes (r = 0, 1, 2, ..., n)

GDC binomcdf Inequality Trap: On TI and Casio calculators, binomcdf(n, p, k) always calculates P(X ≤ k) (up to and including k). For other inequalities with discrete integers, rewrite them in terms of ≤ first:
• P(X < k) = P(X ≤ k - 1)
• P(X ≥ k) = 1 - P(X ≤ k - 1)
• P(X > k) = 1 - P(X ≤ k)

Binomial probabilities and finding the minimum number of trials n

An archer hits the bullseye on any shot with constant probability p = 0.25, independently of other shots.
(a) In 8 shots, find the probability that the archer hits the bullseye at least 3 times. [3 marks]
(b) Find the minimum number of shots n required so that the probability of hitting the bullseye at least once is greater than 0.99. [4 marks]

  1. On a GDC, binomcdf computes P(X ≤ k), so P(X ≥ 3) = 1 − P(X ≤ 2).

    Let X ~ B(8, 0.25). P(X ≥ 3) = 1 − P(X ≤ 2) [M1]
    P(X ≤ 2) = 0.67854... ⇒ P(X ≥ 3) = 1 − 0.67854... ≈ 0.321 (3 s.f.) [A1 A1]

  2. “At least once” is the complement of “zero hits in all n shots,” which has probability (1 − 0.25)ⁿ = 0.75ⁿ.

    1 − 0.75n > 0.99 ⇒ 0.75n < 0.01 [M1 A1]

  3. Dividing by ln(0.75) < 0 reverses the inequality sign. Since n must be an integer, always round up.

    n > ln(0.01)ln(0.75) ≈ 16.008 [M1]
    Therefore, the minimum number of shots is n = 17. [A1]

(a) 0.321; (b) n = 17 shots

A biased five-sided spinner has probability p = 0.20 of landing on red on each spin. If it is spun n = 10 times independently, calculate the probability of obtaining at least 3 reds, giving your answer to 3 s.f.

  1. Rewrite P(X ≥ 3) = 1 - P(X ≤ 2) where X ~ B(10, 0.20).
  2. Using binomcdf(10, 0.20, 2) = 0.6778, subtract from 1.
P(X ≤ 2) = 0.810 + 10(0.2)(0.8)9 + 45(0.2)2(0.8)8 ≈ 0.6778
P(X ≥ 3) = 1 − 0.6778 = 0.322 (3 s.f.)
SL 4.9, 4.12

The Normal distribution and standardization (z-scores)

A continuous random variable X ~ N(μ, σ^2) has a symmetric, bell-shaped probability curve centered at the mean μ (= median = mode), with total area under the curve equal to 1. Notice that for any continuous random variable, the probability of a single exact point is zero (P(X = a) = 0), so P(X < a) = P(X ≤ a).

When μ or σ is unknown, transform X into the standard normal variable Z ~ N(0, 1):

Z = X − μσ ∼ N(0, 1)    ⟺    x − μ = zσ
z
number of standard deviations x lies above (z > 0) or below (z < 0) the mean μ
invNorm(p)
returns the z-score having left-tail area P(Z < z) = p

Classic Paper 2 Chain (Normal → Binomial / Conditional): Part (a) asks for a Normal probability p = P(X > k) for one randomly chosen item. Part (b) then picks a sample of n independent items and asks for the probability that at least r of them satisfy X > k. Recognize this immediately as a transition from X ~ N(μ, σ^2) to a new Binomial variable Y ~ B(n, p)—and keep at least 5 significant figures of p in your GDC for Part (b)!

Finding unknown μ and σ using z-scores and simultaneous equations

The lengths of steel rods follow a Normal distribution X ~ N(μ, σ^2). It is known that 10% of the rods are shorter than 45.0 cm and 5% of the rods are longer than 58.0 cm. Find μ and σ to 3 significant figures. [5 marks]

  1. Standard invNorm uses the area to the LEFT of the boundary. Since P(X > 58) = 0.05, the area to the left of 58 is 0.95.

    P(X < 45) = 0.10 ⇒ z1 = invNorm(0.10) = −1.28155 [A1]
    P(X < 58) = 0.95 ⇒ z2 = invNorm(0.95) = +1.64485 [A1]

  2. Substituting (x₁, z₁) and (x₂, z₂) into (x − μ)/σ = z gives a 2 × 2 linear system.

    (1) 45 − μ = −1.28155σ and (2) 58 − μ = 1.64485σ [M1]

  3. Subtracting eliminates μ immediately.

    13 = (1.64485 − (−1.28155))σ = 2.92640σ ⇒ σ = 4.44 cm [A1]
    μ = 45 + 1.28155(4.4423) = 50.7 cm [A1]

μ = 50.7 cm, σ = 4.44 cm

A normal random variable X ~ N(μ, σ^2) has mean μ = 50. Given that P(X > 65) = P(Z > 1.5), find the standard deviation σ.

  1. Standardize x = 65 using z = (x - μ) / σ.
  2. Solve (65 - 50) / σ = 1.5 for σ.
65 − 50σ = 1.5 ⇒ σ = 151.5 = 10
AHL 4.13–4.14

Bayes' theorem, discrete variance and continuous random variables

When the sample space is partitioned into up to three mutually exclusive and exhaustive events B_1, B_2, B_3 (so P(B_1) + P(B_2) + P(B_3) = 1) and you observe a subsequent event A, Bayes' theorem updates the prior probability P(B_i) to the posterior probability P(B_i | A):

P(Bi | A) = P(Bi) P(A | Bi)P(B1)P(A | B1) + P(B2)P(A | B2) + P(B3)P(A | B3)
Numerator
joint probability P(B_i ∩ A) along the single tree branch through B_i to A
Denominator
total probability P(A) summed over all branches that end at A

Variance, linear transformations and continuous probability density functions

For a discrete random variable X, or a continuous random variable X with probability density function (PDF) f(x), expectation and variance follow parallel sum and integral formulas:

f(x) ≥ 0,   ∫−∞∞ f(x) dx = 1    |    E(X) = μ = ∫−∞∞ x f(x) dx    |    Var(X) = E(X2) − μ2 = ∫−∞∞ x2 f(x) dx − μ2
Mode
the value of x in the domain where f(x) attains its global maximum (check f'(x) = 0 AND domain endpoints!)
Median m
the value m satisfying ∫_{-∞}^m f(x) dx = 0.5 (similarly 0.25 for Q_1 and 0.75 for Q_3)
aX + b
E(aX + b) = a E(X) + b and Var(aX + b) = a^2 Var(X)

Endpoint Mode Trap: Students often set f'(x) = 0 without checking whether the stationary point is actually in the domain or whether an endpoint is higher. If f(x) = (3/8)x^2 on 0 ≤ x ≤ 2, then f(x) is strictly increasing on [0, 2], so its mode is at the right endpoint x = 2 (not at x = 0 where f'(0) = 0)!

Analyzing a continuous random variable: constant k, median, mean and variance

A continuous random variable X has probability density function f(x) = kx(2 - x) for 0 ≤ x ≤ 2, and f(x) = 0 otherwise.
(a) Show that k = 3/4 and state the mode of X. [3 marks]
(b) Find E(X) and Var(X). [4 marks]
(c) Hence find Var(5X - 3). [2 marks]

  1. Total area under any valid PDF must equal 1.

    k ∫02 (2x − x2) dx = k [x2 − x33]02 = k(4 − 83) = 4k3 = 1 ⇒ k = 34 [M1 A1]
    Since f(x) = 34x(2 − x) is a downward parabola symmetric about x = 1, the mode is x = 1. [A1]

  2. By symmetry about x = 1 on [0, 2], E(X) = 1. Then Var(X) = ∫ x² f(x) dx − [E(X)]².

    E(X) = 1 [A1]
    E(X2) = 34 ∫02 (2x3 − x4) dx = 34 [x42 − x55]02 = 34(8 − 325) = 65 [M1 A1]
    Var(X) = E(X2) − [E(X)]2 = 65 − 12 = 15 (or 0.2) [A1]

  3. Subtracting 3 does not change variance; multiplying by 5 multiplies variance by 5² = 25.

    Var(5X − 3) = 52 Var(X) = 25 × 15 = 5 [M1 A1]

(a) k = 3/4, mode = 1; (b) E(X) = 1, Var(X) = 1/5; (c) Var(5X − 3) = 5

In a factory, Machine B_1 produces 60% of bolts (with a 2% defective rate) and Machine B_2 produces 40% of bolts (with a 5% defective rate). Given that a randomly chosen bolt is defective (D), use Bayes' theorem to find the probability P(B_1 | D) that it was made by Machine B_1.

  1. Compute the two defective path probabilities: P(B_1 ∩ D) = 0.60 × 0.02 = 0.012 and P(B_2 ∩ D) = 0.40 × 0.05 = 0.020.
  2. Divide 0.012 by the total defective probability 0.012 + 0.020 = 0.032.
P(B1 | D) = 0.60 × 0.020.60 × 0.02 + 0.40 × 0.05 = 0.0120.032 = 38 = 0.375
