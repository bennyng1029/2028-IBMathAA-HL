Topic 5.3 · AHL 5.12–5.17

First principles, L’Hôpital, implicit, parts and volumes

Guiding questionHow do local linear approximations unlock indeterminate limits, implicit curves, and the exact volume of three-dimensional solids of revolution?

What you need to be able to do

  • Understand continuity and differentiability, and find derivatives from first principles f'(x) = lim_{h->0} (f(x + h) - f(x))/h and higher derivatives f^{(n)}(x).
  • Evaluate indeterminate limits of the form 0/0 or infty/infty using L’Hôpital’s rule, including repeated applications and algebraic rearrangement.
  • Differentiate implicit relations F(x, y) = 0 to find gradients, tangents, horizontal (dy/dx = 0) and vertical (dx/dy = 0) tangents, and solve related rates problems dy/dt = (dy/dx)(dx/dt).
  • Differentiate tan x, sec x, cosec x, cot x, general exponential/log functions (a^x, log_a x) and inverse trig functions (arcsin x, arccos x, arctan x), and integrate their derivatives (e.g. int sec^2 x dx, int sec x tan x dx, int a^x dx, int 1/(1 + x^2) dx); use partial fractions (two distinct linear factors) to rearrange an integrand.
  • Integrate using formal substitution u = g(x) (changing definite limits), integration by parts int u dv = uv - int v du (including repeated and cyclic parts), and double-angle identities.
  • Calculate areas bounded by the y-axis int_c^d |x| dy and volumes of revolution about the x-axis pi int_a^b y^2 dx or y-axis pi int_c^d x^2 dy, including hollow washers between two curves.

AHL 5.12–5.13

First principles, continuity, higher derivatives and L’Hôpital’s rule

A function f(x) is continuous at x = a if its graph has no holes, jumps, or vertical asymptotes there: lim_{x->a^-} f(x) = lim_{x->a^+} f(x) = f(a). It is differentiable at x = a if the secant gradient approaches the same finite value from both the left and the right.

Differentiability vs continuity: Every function that is differentiable at x = a is automatically continuous at x = a. However, the converse is false: a function with a sharp corner or cusp (such as f(x) = |x| at x = 0, where the left gradient is -1 and the right gradient is +1) is continuous but not differentiable at that point.

Differentiation from first principles

When an exam question says “find f'(x) from first principles”, using shortcut derivative rules earns zero marks. You must start from the Formula Booklet limit definition:

f′(x) = dydx = limh→0 f(x + h) − f(x)h
h
horizontal step between x and x + h
(f(x+h) − f(x))/h
gradient of the secant chord through (x, f(x)) and (x + h, f(x + h))

Three algebraic techniques handle first-principles proofs, from polynomials to 1/x and sqrt(x):

  • Polynomials x^n: Expand (x + h)^n using the binomial theorem, cancel x^n, factor out h, and let h -> 0.
  • Fractions like 1/x or 1/x^2: Combine 1/(x + h) - 1/x = (x - (x + h))/(x(x + h)) = -h/(x(x + h)) over a common denominator so h cancels cleanly.
  • Square roots like sqrt(x): Multiply numerator and denominator by the conjugate sqrt(x + h) + sqrt(x) so the numerator becomes (x + h) - x = h.

Higher derivatives f^{(n)}(x)

The n-th derivative of y = f(x) is written f^{(n)}(x) or d^n y / dx^n. On Paper 1 and Paper 3, you are often asked to compute f'(x), f''(x), f'''(x), spot a pattern (such as powers of -1, factorials n!, or phase shifts sin(x + n pi / 2)), and prove the formula for f^{(n)}(x) by mathematical induction.

L’Hôpital’s rule for indeterminate limits

When direct substitution into lim_{x->a} f(x)/g(x) produces the indeterminate form 0/0 or infty/infty, zooming in closely around x = a makes both curves look like their tangent lines. Near x = a when f(a) = g(a) = 0, f(x) ≈ f'(a)(x - a) and g(x) ≈ g'(a)(x - a), so the ratio of heights equals the ratio of gradients:

If limx→a f(x) = limx→a g(x) = 0 (or ±∞), then limx→a f(x)g(x) = limx→a f′(x)g′(x)
f′(x) / g′(x)
differentiate numerator and denominator separately (provided the right-hand limit exists)

Verify 0/0 or infty/infty before every single application! If a limit is lim_{x->0} cos(x)/(x + 2) = 1/2, applying L’Hôpital’s rule gives lim_{x->0} (-sin x)/1 = 0, which is completely wrong because the original limit was 1/2, not 0/0. Beyond the guide, which only uses f(x)/g(x) forms: if you meet a product 0 × infty (such as lim_{x->0^+} x ln x), rewrite it as a fraction (ln x)/(1/x) (-infty/infty) first!

Evaluating a limit that requires applying L’Hôpital’s rule twice

Find the exact value of lim_{x->0} (e^{2x} - 1 - 2x) / (1 - cos(3x)). [5 marks]

  1. IB markschemes require explicit verification that both numerator and denominator approach 0 before applying L’Hôpital’s rule.

    As x → 0: numerator e0 − 1 − 0 = 0 and denominator 1 − cos(0) = 0 (indeterminate form 0/0) [R1]

  2. Differentiate numerator and denominator separately with respect to x using the chain rule.

    limx→0 2e2x − 23 sin(3x) [M1 A1]
    At x = 0: numerator 2 − 2 = 0 and denominator 3 sin(0) = 0 (still form 0/0)

  3. Since the first derivative ratio is still 0/0, differentiate top and bottom one more time and substitute x = 0.

    = limx→0 4e2x9 cos(3x) = 4(1)9(1) = 49 [M1 A1]

AHL 5.14–5.15

Implicit differentiation, related rates and AHL derivatives

Many geometric curves—such as circles x^2 + y^2 = r^2 or rotated ellipses x^2 + xy + y^2 = 7—cannot easily be written in explicit form y = f(x). Using implicit differentiation, we differentiate every term with respect to x directly:

  • Any term involving y is differentiated using the chain rule: d/dx(y^n) = n y^{n-1} (dy/dx) and d/dx(e^y) = e^y (dy/dx).
  • Any mixed product such as x^2 y requires the product rule: d/dx(x^2 y) = x^2 (dy/dx) + 2xy.
  • After differentiating both sides, collect all terms containing dy/dx on the left, factor out dy/dx, and divide.

Exam tip — Horizontal vs vertical tangents on implicit curves: If dy/dx = P(x, y) / Q(x, y):

  • Horizontal tangent (stationary point / parallel to x-axis): Set the numerator P(x, y) = 0, express y in terms of x (or vice versa), and substitute back into the original curve equation to find the coordinates!
  • Vertical tangent (parallel to y-axis): Set the denominator Q(x, y) = 0 (which is equivalent to dx/dy = 0) and substitute back into the original curve equation.

Related rates of change

When two or more quantities vary with time t (such as the volume V, radius r, and depth h of water in a tank), the chain rule connects their rates of change:

dVdt = dVdh × dhdt ⇒ dhdt = dV / dtdV / dh
dV/dt
rate of change of volume with respect to time (positive for inflow, negative for outflow/leaking)
dh/dt
rate of change of height with respect to time

AHL standard derivatives (Formula Booklet 5.15)

In your Formula Booklet (Section 5.15):

  • Reciprocal & tangent trig: d/dx(tan x) = sec^2 x, d/dx(cot x) = -cosec^2 x, d/dx(sec x) = sec x tan x, d/dx(cosec x) = -cosec x cot x. (Notice every “co-” function has a minus sign!)
  • General exponential & log: d/dx(a^x) = a^x ln a and d/dx(log_a x) = 1/(x ln a).
  • Inverse trig: d/dx(arcsin x) = 1/sqrt(1 - x^2), d/dx(arccos x) = -1/sqrt(1 - x^2), and d/dx(arctan x) = 1/(1 + x^2).

Finding points with a vertical tangent on an implicit curve

Consider the curve defined implicitly by x^2 - 2xy + 4y^2 = 12. Find the coordinates of the two points on the curve where the tangent is parallel to the y-axis. [6 marks]

  1. Apply the product rule to −2xy and the chain rule to 4y². Remember that the derivative of 12 is 0.

    2x − 2y − 2xdydx + 8ydydx = 0 [M1 A1]

  2. A tangent parallel to the y-axis is vertical, which occurs where the denominator of dy/dx equals zero (dx/dy = 0).

    dydx = 2y − 2x8y − 2x = y − x4y − x [A1]
    Vertical tangent ⇒ 4y − x = 0 ⇒ x = 4y [M1]

  3. The points must lie on the curve x² − 2xy + 4y² = 12.

    (4y)2 − 2(4y)y + 4y2 = 12 ⇒ 16y2 − 8y2 + 4y2 = 12 ⇒ 12y2 = 12 ⇒ y = ±1 [M1]
    Since x = 4y, the points are (4, 1) and (−4, −1). [A1]

(4, 1) and (−4, −1)

An inverted right circular cone has base radius 6 cm and height 12 cm. Water is poured into the cone at a constant rate of 8 cm3 s-1. Find the rate dh/dt at which the water depth h is rising when h = 4 cm. (Give your answer to 3 s.f. or in terms of pi.)

  1. By similar triangles, r / h = 6 / 12 = 1 / 2, so r = h / 2. Substitute this into V = (1/3)pi r^2 h to get V = (pi / 12) h^3.
  2. Differentiate with respect to h: dV/dh = (pi / 4) h^2. At h = 4, dV/dh = 4pi, so dh/dt = (dV/dt) / (dV/dh) = 8 / (4pi) = 2 / pi.
r = 12h ⇒ V = 13πh24h = π12h3 ⇒ dVdh = π4h2
At h = 4: dhdt = 8(π/4)(42) = 2π ≈ 0.637 cm s−1
AHL 5.15–5.16

Standard AHL integrals, substitution, integration by parts and partial fractions

1. Standard AHL integrals leading to arcsin and arctan

The Formula Booklet gives two essential inverse trigonometric integrals for any positive constant a > 0:

∫ 1a2 + x2 dx = 1a arctanxa + C, ∫ 1√(a2 − x2) dx = arcsinxa + C (|x| < a)
1/a in arctan
present in arctan, but NOT in arcsin!

The booklet also gives int a^x dx = a^x / ln a + C (a > 0, a != 1), the reverse of d/dx(a^x) = a^x ln a. For example, int_0^1 2^x dx = [2^x / ln 2]_0^1 = 1/ln 2.

When the denominator is an irreducible quadratic such as x^2 + 6x + 25, complete the square first: x^2 + 6x + 25 = (x + 3)^2 + 4^2, which integrates directly to (1/4) arctan((x + 3)/4) + C.

2. Formal integration by substitution

To evaluate int_a^b f(g(x)) g'(x) dx using u = g(x):

  1. Differentiate the substitution: du/dx = g'(x) => du = g'(x) dx.
  2. Change the limits of integration: lower limit u_1 = g(a), upper limit u_2 = g(b).
  3. Rewrite the entire integrand in terms of u and evaluate int_{u_1}^{u_2} f(u) du directly—no back-substitution needed!

3. Integration by parts (LIATE)

Reversing the product rule gives the integration by parts formula in Section 5.16 of the Formula Booklet:

∫ u dvdx dx = uv − ∫ v dudx dx
u
factor chosen to be differentiated (pick using LIATE: Log → Inverse trig → Algebraic → Trig → Exp)
dv/dx
factor chosen to be integrated to find v

Three classic IB integration by parts patterns:

  • Polynomial times e^{kx}, sin(kx), or cos(kx): Choose u = x^n so each differentiation lowers the power of x until it becomes a constant.
  • Lone ln x, arcsin x, or arctan x (or multiplied by x^n): Always choose the log or inverse trig function as u! For int ln x dx, let u = ln x and dv/dx = 1, giving x ln x - int x(1/x) dx = x ln x - x + C.
  • Cyclic I = int e^{ax} sin(bx) dx or int e^{ax} cos(bx) dx: Integrate by parts twice (keeping u = e^{ax} both times) until the original integral I reappears on the right-hand side, then solve algebraically for I.

4. Integration using partial fractions

When integrating a rational function P(x)/Q(x) where the denominator factors into distinct linear terms (x - a)(x - b), decompose the fraction first (from Topic 1.3 / AHL 1.11):

int (px + q)/((x - a)(x - b)) dx = int (A/(x - a) + B/(x - b)) dx = A ln|x - a| + B ln|x - b| + C.

Definite integration by parts with an inverse trigonometric function

Find the exact value of int_0^1 arctan(x) dx. [5 marks]

  1. For a lone inverse trig function, set u = arctan x and dv/dx = 1 so that du/dx is purely algebraic.

    Let u = arctan x ⇒ dudx = 11 + x2, and dvdx = 1 ⇒ v = x [M1 A1]

  2. Substitute into [uv] − ∫ v du and recognize the remaining integral as a logarithmic inspection form.

    ∫01 arctan x dx = [x arctan x]01 − ∫01 x1 + x2 dx [A1]

  3. Since d/dx(1 + x²) = 2x, the integral of x/(1 + x²) is (1/2) ln(1 + x²).

    = [x arctan x − 12 ln(1 + x2)]01 = (1 · π4 − 12 ln 2) − (0 − 0) = π4 − 12 ln 2 [M1 A1]

π/4 − (1/2) ln 2

Find the exact value of int_0^3 2 / (x^2 + 9) dx. (You can type an exact expression in terms of pi such as pi/3, or a 3 s.f. decimal.)

  1. Match the integrand with the Formula Booklet standard integral int 1/(a^2 + x^2) dx = (1/a) arctan(x/a) + C where a = 3.
  2. Factor out the 2 to get [(2/3) arctan(x/3)]_0^3 and use arctan(1) = pi/4.

AHL 5.17

Area with the y-axis and volumes of revolution

When a region is bounded by a curve x = g(y) and the y-axis between y = c and y = d, slicing horizontally into strips of thickness dy gives the area A = int_c^d |x| dy.

If we rotate that region through 2pi radians (360°) about one of the coordinate axes, each thin slice sweeps out a circular disc of radius R and area pi R^2:

Vx = π ∫ab y2 dx (about the x-axis), Vy = π ∫cd x2 dy (about the y-axis)
Vx
volume when rotated 2π radians about the x-axis (radius = y, limits are x-values)
Vy
volume when rotated 2π radians about the y-axis (radius = x, limits are y-values)

Hollow solids between two curves (the washer method)

When the region enclosed between an outer curve y_{outer} = f(x) and an inner curve y_{inner} = g(x) (with f(x) >= g(x) >= 0) is rotated about the x-axis, each vertical cross-section is a hollow ring (washer) whose area is the outer circle minus the inner hole:

V = pi int_a^b ([y_{outer}]^2 - [y_{inner}]^2) dx = pi int_a^b ([f(x)]^2 - [g(x)]^2) dx.

Never square the difference! Writing pi int_a^b (y_1 - y_2)^2 dx instead of pi int_a^b (y_1^2 - y_2^2) dx is the most common volume mistake in IB HL exams. Always subtract the squared radii: outer squared minus inner squared.

Not needed for IB — Cylindrical shells: The cylindrical shell method (V = 2pi int_a^b x y dx) often taught in other calculus courses and textbooks is not in the IB Math AA HL syllabus. For rotation about the y-axis, rearrange the curve for x^2 in terms of y and use V = pi int_c^d x^2 dy.

Volume of revolution between two curves about the x-axis

The region R is enclosed by the curve y = sqrt(x) and the line y = x / 2 in the first quadrant. Find the exact volume of the solid formed when R is rotated through 2pi radians about the x-axis. [6 marks]

  1. Equating the two curves gives the limits of integration a and b along the x-axis.

    √x = x2 ⇒ x = x24 ⇒ x2 − 4x = 0 ⇒ x = 0 or x = 4 [M1 A1]

  2. On [0, 4], √x ≥ x/2, so y_outer = √x and y_inner = x/2. Square each radius separately before subtracting.

    V = π ∫04 ((√x)2 − (x2)2) dx = π ∫04 (x − x24) dx [M1 A1]

  3. Use the power rule and substitute x = 4 and x = 0.

    V = π [x22 − x312]04 = π (8 − 6412) = π (8 − 163) = 8π3 [M1 A1]

8π/3

The region bounded by the curve y = x^2, the y-axis, and the horizontal line y = 4 in the first quadrant is rotated through 2pi radians about the y-axis. Find the volume of the solid generated (type an exact multiple of pi such as 3*pi, or a 3 s.f. decimal).

  1. For rotation about the y-axis, use V = pi int_c^d x^2 dy. Since y = x^2, we can substitute x^2 = y directly!
  2. Integrate with respect to y from y = 0 to y = 4: V = pi int_0^4 y dy = pi [y^2 / 2]_0^4.
V = π ∫04 x2 dy = π ∫04 y dy = π [y22]04 = 8π ≈ 25.1
