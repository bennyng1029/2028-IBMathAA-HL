Topic 1.5 · SL 1.6 + AHL 1.15–1.16

Mathematical proof and systems of linear equations

Guiding questionHow do we establish beyond doubt that a mathematical statement holds for infinitely many cases—or determine exactly when a system of equations has one, none, or infinitely many solutions?

What you need to be able to do

  • Construct a rigorous left-hand-side to right-hand-side (LHS -> RHS) algebraic proof for identities, parity properties, and positivity (by completing the square).
  • Prove statements involving series, divisibility, derivatives, and inequalities by mathematical induction using the full IB four-step structure and conclusion sentence.
  • Use proof by contradiction to establish irrationality (such as sqrt(2) or log_2 5) and parity/divisibility results.
  • Disprove a universal conjecture by providing a single explicit counterexample.
  • Solve up to 3 × 3 systems of linear equations both algebraically (Gaussian elimination) and with technology (GDC solver or row reduction), and determine conditions on a parameter k for a unique solution, no solution, or infinitely many solutions.

Question decoder: spotting which proof or system method to use

Proof and linear system questions use strict IB command terms. Use this decoder to match the exact exam wording to the required layout and markscheme checkpoints.

• No solution: g(k) = 0 and h(k) != 0.
• Infinite solutions: g(k) = 0 and h(k) = 0 (set z = lambda \in \mathbb{R}).
SL 1.6

Deductive algebraic proof and identities

A direct deductive proof uses general algebraic symbols—never just a few numerical examples—to show that a statement is true for every value in its domain. An identity (LHS == RHS) holds for all values of the variable, whereas a conditional equation holds only for specific roots.

The symbol == means “is identically equal to”: (x + 1)^2 == x^2 + 2x + 1 is true for every x. The symbol = in an equation such as x^2 = 4 is true only for particular values (here x = +- 2).

Three golden rules for SL 1.6 “Show that / Prove that” questions

  1. Work in one direction (LHS -> RHS): Pick one side (almost always the side with more terms or fractions) and simplify it step by step until it matches the other side. Never start by assuming the conclusion LHS = RHS and cross-multiplying!
  2. Use standard integer representations:
    • Any even integer: 2n (n \in \mathbb{Z}); any odd integer: 2n + 1.
    • Consecutive integers: n, n + 1, n + 2 (or n - 1, n, n + 1 so symmetric terms cancel!).
    • A multiple of m: m k where k \in \mathbb{Z}.
    • A two-digit integer with tens digit a and units digit b: 10a + b (reversed: 10b + a).
  3. Complete the square to prove inequalities (>= 0 or > 0): Every real square satisfies A^2 >= 0. Rewriting a quadratic as a(x - h)^2 + k with a > 0, k > 0 immediately proves it is strictly positive for all real x.

Exam tip (AG = Answer Given): In any “Show that…” question, the target expression is printed on the exam paper. Examiners will award zero marks for the final step if you jump over the unsimplified expansion right before the given answer. Show one extra line of working!

Direct algebraic proof with consecutive odd integers and completing the square

(a) Prove algebraically that the difference between the squares of any two consecutive odd integers is always a multiple of 8. [3 marks]

(b) Prove that a^2 + b^2 + 2c^2 - 2ac - 2bc >= 0 for all real numbers a, b, c \in \mathbb{R}. [3 marks]

  1. Any odd integer can be written as 2n − 1, so the next consecutive odd integer is 2n + 1 (for n ∈ ℤ).

    Let the two consecutive odd integers be 2n − 1 and 2n + 1 (n ∈ ℤ). [M1]

  2. Expanding (2n + 1)² − (2n − 1)² cancels 4n² and 1, leaving 8n.

    LHS = (2n + 1)2 − (2n − 1)2 = (4n2 + 4n + 1) − (4n2 − 4n + 1) = 8n [A1]
    Since n ∈ ℤ, 8n is a multiple of 8. [R1]

  3. Grouping a² − 2ac + c² and b² − 2bc + c² turns the expression into the sum of two squares of real numbers.

    LHS = (a2 − 2ac + c2) + (b2 − 2bc + c2) = (a − c)2 + (b − c)2 [M1 A1]
    Since (a − c)2 ≥ 0 and (b − c)2 ≥ 0 for all a, b, c ∈ ℝ, their sum is ≥ 0. [R1]

(a) (2n+1)² − (2n−1)² = 8n    (b) (a − c)² + (b − c)² ≥ 0

A three-digit integer has hundreds digit a, tens digit b, and units digit c (with a > c), so its value is 100a + 10b + c. When its digits are reversed, the new number is 100c + 10b + a. The difference between the original number and the reversed number is always divisible by a largest positive integer M regardless of a, b, c. Enter the value of M.

  1. Subtract the reversed number from the original: (100a + 10b + c) - (100c + 10b + a).
  2. Notice that 10b cancels completely, leaving 99a - 99c = 99(a - c).
(100a + 10b + c) − (100c + 10b + a) = 99a − 99c = 99(a − c)
AHL 1.15

Proof by mathematical induction

Mathematical induction proves an infinite sequence of statements P(1), P(2), P(3), ... in the same way an infinite line of dominoes falls: if you knock over the first domino (P(1) is true), and you prove that any domino falling knocks over the very next domino (P(k) => P(k + 1)), then every domino P(n) for n \in \mathbb{Z}^+ must fall.

Before you start: induction proofs of series use sigma notation from 1.1 Sequences, series and financial models; proofs about f^{(n)}(x) use the product and chain rules from 5.1 Differentiation, curve analysis and optimization; and the induction proof of De Moivre’s theorem (1.4 Complex numbers and De Moivre’s theorem) uses the compound-angle identities from 3.2 The unit circle, trig identities and periodic models.

The mandatory 4-step IB markscheme template (memorize word-for-word):

  1. Base case (n = 1, or initial n_0): Compute LHS and RHS separately (or evaluate f(1)) and write: “Therefore P(1) is true.” [A1]
  2. Inductive hypothesis (n = k): Write: “Assume P(k) is true for some k \in \mathbb{Z}^+” and state the n = k equation explicitly. [M1]
  3. Inductive step (n = k + 1): Start from the n = k + 1 expression, explicitly substitute your inductive hypothesis, and factor/simplify to the exact (k + 1) target form. [M1 A1 A1]
  4. Conclusion sentence: “Since P(1) is true, and P(k) being true implies P(k + 1) is true, by the principle of mathematical induction, P(n) is true for all n \in \mathbb{Z}^+.” [R1]

Never write “Assume P(k) is true for all k”! If you assume it is true for all k, you have assumed what you are trying to prove. Always write “for some k \in \mathbb{Z}^+”. Also note that the final [R1] mark for the conclusion sentence is only awarded if at least the base case and inductive hypothesis substitution were attempted.

How to execute the inductive step (n = k + 1) across all 4 IB question types

  • 1. Series summations (Sigma_{r=1}^n u_r = S(n)): Split off the last term: Sigma_{r=1}^{k+1} u_r = (Sigma_{r=1}^k u_r) + u_{k+1} = S(k) + u_{k+1}. Factor out common factors like (k + 1) or k! or 2^k immediately instead of expanding everything into a giant polynomial!
  • 2. Divisibility (“f(n) is divisible by m”): In your hypothesis, write f(k) = m A for some A \in \mathbb{Z}, isolate the highest exponential term (e.g. 7^k = 6A + 1 or 5^{2k} = 24A + 1), and substitute it straight into f(k + 1).
  • 3. Higher derivatives (f^{(n)}(x)): Differentiate your n = k formula once with respect to x using the product, quotient, or chain rule: f^{(k+1)}(x) = d/dx [f^{(k)}(x)].
  • 4. Inequalities (L(n) > R(n)): Start with L(k + 1), apply the inductive hypothesis inequality to replace L(k) with R(k), and show that the resulting expression is > R(k + 1).

Proving divisibility by mathematical induction

Prove by mathematical induction that f(n) = 5^{2n} - 1 is divisible by 24 for all n \in \mathbb{Z}^+. [6 marks]

  1. Evaluate f(1) explicitly and show it is an integer multiple of 24.

    For n = 1: f(1) = 52(1) − 1 = 25 − 1 = 24 = 24(1), which is divisible by 24. Hence P(1) is true. [A1]

  2. Assume P(k) holds for some positive integer k, and isolate 52k so we can substitute it cleanly into f(k+1).

    Assume P(k) is true for some k ∈ ℤ+: 52k − 1 = 24A for some A ∈ ℤ ⇒ 52k = 24A + 1. [M1]

  3. Rewrite 52(k+1) as 5² · 52k = 25 · 52k, substitute 52k = 24A + 1, and factor out 24.

    For n = k + 1: f(k + 1) = 52(k+1) − 1 = 52 · 52k − 1 = 25(24A + 1) − 1 [M1 A1]
    f(k + 1) = 25(24A) + 25 − 1 = 24(25A + 1), which is divisible by 24 since 25A + 1 ∈ ℤ. [A1]

  4. State the principle of mathematical induction linking the base case and the inductive step.

    Since P(1) is true, and P(k) being true implies P(k + 1) is true, by the principle of mathematical induction P(n) is true for all n ∈ ℤ+. [R1]

f(k+1) = 24(25A + 1), divisible by 24 for all n ∈ ℤ⁺

Consider the proposition that f(n) = 3^{2n} + 7 is divisible by m for all n \in \mathbb{Z}^+. By testing n = 1 and n = 2 (or setting up the inductive step f(k+1) = 9(3^{2k} + 7) - 56), find the largest positive integer m for which this statement holds for all n \in \mathbb{Z}^+.

  1. Evaluate f(1) = 3^2 + 7 = 16 and f(2) = 3^4 + 7 = 88.
  2. Find gcd(16, 88), and notice in the inductive step that f(k+1) = 9 f(k) - 56 = 8(9A - 7).
f(1) = 16, f(2) = 88 ⇒ gcd(16, 88) = 8
Inductive step: 32(k+1) + 7 = 9(8A − 7) + 7 = 72A − 56 = 8(9A − 7)
AHL 1.15

Proof by contradiction and disproof by counterexample

Proof by contradiction

In a proof by contradiction, to prove a statement P is true, we begin by assuming P is false (its logical negation not P is true). We then follow valid algebraic steps until we reach a statement that contradicts either our initial assumption or a known mathematical fact.

Two classic IB contradiction proofs

  • Irrationality of sqrt(p) (for prime p, e.g. sqrt(2), sqrt(3), sqrt(5)): Assume sqrt(p) is rational, so sqrt(p) = a / b where a, b \in \mathbb{Z}^+ and gcd(a, b) = 1 (no common factors). Squaring gives a^2 = p b^2, so p divides a^2, which (since p is prime) implies p divides a. Write a = p k (k \in \mathbb{Z}); substituting gives p^2 k^2 = p b^2 => b^2 = p k^2, so p also divides b. Thus p is a common factor of a and b, contradicting gcd(a, b) = 1!
  • Irrationality of log_a b (when a, b have different prime factors, e.g. log_2 5): Assume log_2 5 = p / q where p, q \in \mathbb{Z}^+. Rewriting in exponential form gives 2^{p/q} = 5 => 2^p = 5^q. However, for any p, q \in \mathbb{Z}^+, 2^p is always even while 5^q is always odd—a contradiction!

Disproof by counterexample

To prove a universal statement (“For all x \in S, property Q(x) holds”) is false, you only need to exhibit one single counterexample x_0 \in S for which Q(x_0) is false. (Disproof by counterexample is examinable in May 2028.)

  • Conjecture: “For all real numbers x, y, if x^2 > y^2, then x > y.” → False: take x = -3, y = 1. Then x^2 = 9 > 1 = y^2, but -3 < 1.
  • Conjecture: “n^2 + n + 41 is prime for all n \in \mathbb{Z}^+.” → False: take n = 41. Then 41^2 + 41 + 41 = 41(41 + 1 + 1) = 41 × 43, which is composite.

Proving irrationality by contradiction

Prove by contradiction that sqrt(3) is irrational. [5 marks]

  1. Assume √3 is rational and write it as a fraction a/b where a and b share no common factors other than 1.

    Assume, for a contradiction, that √3 is rational, so √3 = ab where a, b ∈ ℤ+ and gcd(a, b) = 1. [M1]

  2. Since 3 is prime, if 3 divides a², then 3 must divide a itself.

    3 = a2b2 ⇒ a2 = 3b2. Hence 3 divides a2, and since 3 is prime, 3 divides a. [M1 A1]

  3. Showing 3 divides both a and b contradicts gcd(a, b) = 1.

    Let a = 3k (k ∈ ℤ). Then (3k)2 = 3b2 ⇒ 9k2 = 3b2 ⇒ b2 = 3k2. [M1]
    Thus 3 also divides b2 and hence 3 divides b. This contradicts gcd(a, b) = 1; therefore √3 is irrational. [R1]

3 divides both a and b, contradicting gcd(a, b) = 1 ⇒ √3 is irrational

A student claims that the number f(n) = 2^n - 1 is prime for every prime number n. While this is true for n = 2, 3, 5, 7, it fails at the next prime n = 11 because 2^{11} - 1 = 2047 = 23 × 89. Now consider a simpler claim: “n^2 - n + 5 is prime for all positive integers n.” Find the smallest integer n >= 2 that serves as a counterexample.

  1. Test n = 2, 3, 4, 5 in n^2 - n + 5.
  2. For n = 2: 7 (prime). For n = 3: 11 (prime). For n = 4: 17 (prime). What happens at n = 5?
For n = 5: 52 − 5 + 5 = 25 = 5 × 5, which is composite (not prime).
AHL 1.16

Systems of linear equations (up to 3 variables)

Before you start: the geometric meaning of each case (three planes meeting at a point, in a line, or not at all) uses planes and normal vectors from 3.3 Vectors, lines and planes in 3D space.

A system of three linear equations in three unknowns x, y, z represents three planes in 3D space (AHL 3.18, site page 3.3). We solve and classify the system algebraically using Gaussian elimination: use the first equation to eliminate x from equations 2 and 3, then use the new second equation to eliminate y from equation 3, arriving at an upper-triangular (row-echelon) system:

[ a1   b1   c1  |  d1 ]
[ 0    b2   c2  |  d2 ]
[ 0    0    g(k) |  h(k) ]

Classifying the 3 outcomes from the final reduced row g(k) z = h(k)

Classification of a 3 × 3 linear system after Gaussian elimination
Condition on Row 3: g(k) z = h(k) Algebraic outcome 3D geometric meaning (AHL 3.18, site page 3.3)
g(k) != 0 Unique solution (consistent): z = h(k) / g(k), then back-substitute to find unique y and x. The three planes intersect at a single point (x, y, z).
g(k) = 0 and h(k) != 0 No solution (inconsistent): Row 3 reads 0 = h(k) != 0, which is impossible. The planes form a triangular prism (pairwise intersecting in 3 parallel lines) or two/three planes are parallel and distinct.
g(k) = 0 and h(k) = 0 Infinitely many solutions (dependent): Row 3 reads 0 = 0. Let z = lambda (lambda \in \mathbb{R}) and back-substitute into Row 2 and Row 1. The three planes meet along a common line of intersection \mathbf{r} = \mathbf{a} + \lambda \mathbf{b} (a sheaf of planes) or are coincident.

Not needed for IB Math AA HL: Matrix algebra, 3 × 3 determinants (det(A) = 0), inverse matrices A^{-1}, Cramer's rule and eigenvalues are not in the IB Math AA HL syllabus.

Row reduction is examinable (AHL 1.16): you may write the row operations on an augmented matrix, and on Paper 2 you should use your GDC's system solver or rref to solve or check a system with numerical coefficients. With a parameter k, use elimination (row reduction) to reach g(k)z = h(k): a zero coefficient alone cannot tell no solution from infinitely many solutions, so check the consistency of the right-hand side.

Never divide a row by an expression containing the parameter k! Dividing Row 2 by (k - 2) silently assumes k != 2, which destroys the exact singular value the question is asking you to investigate. Multiply rows by constants or expressions only when keeping track of zero factors.

Finding parameter values for no solution and infinitely many solutions

Consider the system of linear equations:

x + y + z = 2
2x + 3y + 4z = 5
3x + 4y + (k^2 - 4)z = k + 4,   where k \in \mathbb{R}.

(a) Find the value(s) of k for which the system has: (i) a unique solution, (ii) no solution, (iii) infinitely many solutions. [6 marks]

(b) For the value of k that gives infinitely many solutions, find the general solution in terms of a real parameter lambda. [2 marks]

  1. Subtracting 2×(Row 1) from Row 2 and 3×(Row 1) from Row 3 zeroes out the x-column below Row 1.

    R2 − 2R1:   y + 2z = 1 [M1 A1]
    R3 − 3R1:   y + (k2 − 7)z = k − 2 [A1]

  2. Subtracting the new Row 2 from the new Row 3 isolates z in the form g(k)z = h(k).

    R3 − R2:   (k2 − 9)z = k − 3 ⇔ (k − 3)(k + 3)z = k − 3 [M1 A1]
    (i) Unique solution: k2 − 9 ≠ 0 ⇒ k ≠ 3 and k ≠ −3.
    (ii) No solution: k = −3 gives 0z = −6 (inconsistent), so k = −3.
    (iii) Infinite solutions: k = 3 gives 0z = 0, so k = 3. [A1]

  3. With Row 3 reduced to 0 = 0, z is a free parameter λ ∈ ℝ.

    Let z = λ (λ ∈ ℝ). From R2: y = 1 − 2z = 1 − 2λ [M1]
    From R1: x = 2 − y − z = 2 − (1 − 2λ) − λ = 1 + λ [A1]

(a) Unique: k ≠ ±3; No solution: k = −3; Infinite: k = 3    (b) (x, y, z) = (1 + λ, 1 − 2λ, λ)

The system of equations x + 2y - z = 3, 2x + 5y + z = 8, and 3x + 7y + kz = 11 has infinitely many solutions for a specific real constant k. When z = 2, find the value of x + y + k.

  1. Notice that R_1 + R_2 on the left-hand side has (1+2)x + (2+5)y = 3x + 7y, which matches R_3! Also 3 + 8 = 11. Thus for infinite solutions we need k = -1 + 1 = 0.
  2. Now set z = 2 in x + 2y = 3 + z = 5 and 2x + 5y = 8 - z = 6 to find x = 13, y = -4, and compute x + y + k.
R3 = R1 + R2 ⇒ k = −1 + 1 = 0
For z = 2: y = 2 − 3(2) = −4, x = 3 − 2(−4) + 2 = 13 ⇒ x + y + k = 13 − 4 + 0 = 9
