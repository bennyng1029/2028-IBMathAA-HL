Topic 5.2 · SL 5.5, 5.9–5.11

Integration, areas between curves and kinematics

Guiding questionHow does reversing differentiation let us reconstruct a function from its rate of change, measure exact areas between curves, and track the motion of a particle?

What you need to be able to do

  • Integrate powers x^n (n != -1), 1/x, sin x, cos x, and e^x, including linear composites f(ax + b), and find the constant of integration +C from a boundary condition.
  • Recognize and evaluate integrals of the form int k g'(x) f(g(x)) dx by inspection (reverse chain rule) or substitution.
  • Evaluate definite integrals using the Fundamental Theorem of Calculus int_a^b f'(x) dx = f(b) - f(a) and apply definite integral properties.
  • Find the area enclosed between a curve and the x-axis (int_a^b |y| dx) and the area enclosed between two curves (int_a^b (y_top - y_bottom) dx).
  • Move between displacement s(t), velocity v(t) = s'(t), and acceleration a(t) = v'(t), and distinguish net displacement int_{t_1}^{t_2} v(t) dt from total distance travelled int_{t_1}^{t_2} |v(t)| dt.

SL 5.5, 5.10

Indefinite integrals, standard forms and the reverse chain rule

Integration (anti-differentiation) reverses differentiation: if F'(x) = f(x), then the indefinite integral is int f(x) dx = F(x) + C. Because any constant disappears when differentiated (d/dx (C) = 0), you must always include + C on an indefinite integral. If the question gives one point (x_0, y_0) on the curve (a boundary condition or initial condition), substitute x = x_0 and y = y_0 to find the exact value of C.

In your formula booklet (SL 5.5 & 5.10): Standard integrals given in the booklet:

  • int x^n dx = x^{n+1} / (n + 1) + C (n != -1)
  • int (1/x) dx = ln|x| + C
  • int sin x dx = -cos x + C and int cos x dx = sin x + C
  • int e^x dx = e^x + C

Composites with a linear inner function (ax + b)

When differentiating F(ax + b), the chain rule multiplies by the constant a. Therefore, when integrating f(ax + b), you reverse that step by dividing by a (multiplying by 1/a):

  • int (ax + b)^n dx = (ax + b)^{n+1} / [a(n + 1)] + C (n != -1)
  • int (1 / (ax + b)) dx = (1/a) ln|ax + b| + C
  • int e^{ax+b} dx = (1/a) e^{ax+b} + C
  • int sin(ax + b) dx = -(1/a) cos(ax + b) + C and int cos(ax + b) dx = (1/a) sin(ax + b) + C

Common mistake — Dividing by a non-linear derivative: The “divide by a” shortcut works only when the inside function is linear (ax + b, whose derivative a is a constant). You can never integrate int e^{x^2} dx as e^{x^2} / (2x)! If the inside function is non-linear (like x^2 or sin x), its derivative g'(x) must already be multiplying the integrand outside.

Integration by inspection (reverse chain rule) and u-substitution

Whenever an integrand contains a composite function f(g(x)) multiplied by a constant multiple of the inner derivative g'(x), set u = g(x) so that du = g'(x) dx:

∫ g'(x) f(g(x)) dx = ∫ f(u) du = F(g(x)) + C
u = g(x)
inner function (inside a power, root, exponent, denominator, or trig function)
du = g'(x) dx
differential that absorbs the outside factor g'(x) dx

Three reverse-chain-rule patterns appear constantly on Paper 1:

  1. Power / root pattern: int 6x (3x^2 + 1)^4 dx. Since d/dx (3x^2 + 1) = 6x, this is int u^4 du = (3x^2 + 1)^5 / 5 + C.
  2. Exponential pattern: int x e^{x^2} dx. Since d/dx (x^2) = 2x, adjust by 1/2: (1/2) int 2x e^{x^2} dx = (1/2) e^{x^2} + C.
  3. Logarithmic fraction pattern (g'(x) / g(x)): Whenever the numerator of a fraction is a constant multiple of the derivative of the denominator, the integral is a natural logarithm! For example, int (cos x / (2 + sin x)) dx = ln|2 + sin x| + C, and int (x / (x^2 + 4)) dx = (1/2) ln(x^2 + 4) + C.

Finding a function from its gradient and a boundary condition

The gradient of a curve y = f(x) at any point (x, y) is given by f'(x) = (6x) / (x^2 + 3) + 4 e^{-2x}. Given that the curve passes through the point (0, 3 ln 3), find an expression for f(x). [6 marks]

  1. For 6x / (x² + 3), the derivative of the denominator x² + 3 is 2x, so 6x = 3(2x). For 4e⁻²ˣ, the linear coefficient is a = −2.

    f(x) = ∫ 3(2x)x2 + 3 dx + ∫ 4e−2x dx [M1]
    f(x) = 3 ln(x2 + 3) + 4−2e−2x + C = 3 ln(x2 + 3) − 2e−2x + C [A1 A1]

  2. Remember that e⁰ = 1 (never 0!), so substituting x = 0 does not make the exponential term vanish.

    f(0) = 3 ln(0 + 3) − 2e0 + C = 3 ln 3 [M1]
    3 ln 3 − 2 + C = 3 ln 3 ⇒ C = 2 [A1]

  3. Substitute C = 2 back into f(x).

    f(x) = 3 ln(x2 + 3) − 2e−2x + 2 [A1]

f(x) = 3 ln(x^2 + 3) - 2e^{-2x} + 2

A curve satisfies f'(x) = 6x (x^2 - 1)^2 and passes through the point (1, 14). Calculate the value of the y-intercept f(0).

  1. Let u = x^2 - 1 so du = 2x dx. Then f(x) = int 3(2x)(x^2 - 1)^2 dx = (x^2 - 1)^3 + C.
  2. Use f(1) = (1^2 - 1)^3 + C = 14 to find C = 14, then evaluate f(0) = (0 - 1)^3 + 14.
f(x) = (x2 − 1)3 + C;   f(1) = 0 + C = 14 ⇒ C = 14

SL 5.5, 5.11

Definite integrals, signed integrals vs geometric area, and area between curves

By the Fundamental Theorem of Calculus, if F(x) is any antiderivative of f(x), then:

∫ab f(x) dx = [F(x)]ab = F(b) − F(a)
a, b
lower and upper limits of integration
F(x)
any antiderivative satisfying F'(x) = f(x) (the +C cancels in F(b) − F(a))

Key properties of definite integrals

Paper 1 frequently tests whether you can manipulate definite integrals without knowing the formula for f(x):

  • Reversing limits flips the sign: int_b^a f(x) dx = - int_a^b f(x) dx, and int_a^a f(x) dx = 0.
  • Linearity: int_a^b [k f(x) + c] dx = k int_a^b f(x) dx + c(b - a). (Watch out for the constant c: integrating a constant c from a to b gives c(b - a), not just c!)
  • Additivity over adjacent intervals: int_a^b f(x) dx + int_b^c f(x) dx = int_a^c f(x) dx.
  • Horizontal shift: int_a^b f(x - k) dx = int_{a-k}^{b-k} f(u) du (the curve y = f(x - k) is y = f(x) shifted right by k, so the area under it on [a, b] equals the area under f on [a - k, b - k]).

Signed definite integral vs enclosed geometric area

A definite integral int_a^b f(x) dx is a signed sum: regions where f(x) > 0 (above the x-axis) contribute positively, while regions where f(x) < 0 (below the x-axis) contribute negatively. In contrast, the geometric area enclosed by a curve and the x-axis is always positive:

  • Area between y = f(x) and the x-axis on [a, b]: A = int_a^b |f(x)| dx. If f(x) crosses the x-axis at x = c with f(x) >= 0 on [a, c] and f(x) <= 0 on [c, b], split the integral at c: A = int_a^c f(x) dx - int_c^b f(x) dx.
  • Area enclosed between two curves y = f(x) and y = g(x): First solve f(x) = g(x) to find the intersection x-coordinates a and b. Then integrate the upper curve minus the lower curve: A = int_a^b (y_top - y_bottom) dx = int_a^b |f(x) - g(x)| dx. Because y_top - y_bottom >= 0, this formula automatically gives the right positive area even when one or both curves dip below the x-axis!

Not needed for IB (Scope boundary): Numerical approximation of definite integrals using the trapezoidal rule (or Simpson's rule) belongs to IB Math AI, not IB Math AA! In Math AA, definite integrals are evaluated either analytically on Paper 1 or directly via your GDC's fnInt (int) command on Paper 2.

Finding the exact area enclosed between a parabola and a line

Find the exact area of the finite region enclosed by the parabola y = 6 - x^2 and the line y = x + 4. [6 marks]

  1. The limits of integration a and b are the x-values where the two curves cross.

    6 − x2 = x + 4 ⇒ x2 + x − 2 = 0 ⇒ (x + 2)(x − 1) = 0 [M1]
    x = −2 and x = 1 [A1]

  2. At x = 0 ∈ (−2, 1), the parabola has y = 6 while the line has y = 4, so the parabola is on top.

    A = ∫−21 ((6 − x2) − (x + 4)) dx = ∫−21 (2 − x − x2) dx [M1 A1]

  3. Use brackets around F(−2) to avoid sign errors with negative powers.

    A = [2x − x22 − x33]−21 = (2 − 12 − 13) − (−4 − 2 + 83) [M1]
    A = 76 − (−103) = 276 = 92 (or 4.5) [A1]

9/2 (or 4.5)

Given that int_1^4 f(x) dx = 5, calculate the value of int_1^4 (2 f(x) + 1) dx + int_4^1 f(x) dx.

  1. Split the first integral using linearity: 2 int_1^4 f(x) dx + int_1^4 1 dx. Remember that int_1^4 1 dx = 1(4 - 1) = 3!
  2. For the second term, reversing the limits flips the sign: int_4^1 f(x) dx = -int_1^4 f(x) dx = -5.
2 ∫14 f(x) dx + ∫14 1 dx − ∫14 f(x) dx = 2(5) + 1(4 − 1) − 5 = 8
SL 5.9

Kinematics: displacement, velocity, acceleration and total distance

In one-dimensional kinematics, a particle moves along a straight line (usually the x-axis or s-axis) with position or displacement s(t) relative to an origin O at time t >= 0. Differentiation moves forward from position to velocity to acceleration, while integration moves backward:

s(t)   -- d/dt -->   v(t) = dsdt   -- d/dt -->   a(t) = dvdt = d2sdt2
v(t) = ∫ a(t) dt
velocity (signed rate of change of displacement; speed is |v(t)|)
Δs = ∫t₁t₂ v(t) dt
net displacement s(t2) − s(t1) over [t1, t2]
d = ∫t₁t₂ |v(t)| dt
total distance travelled over [t1, t2]

Displacement vs total distance travelled

Suppose a runner starts at the origin O, runs 10 m East (+10), turns around, and runs 4 m West (-4):

  • Their net displacement is Delta s = int_{t_1}^{t_2} v(t) dt = +10 - 4 = +6 m (how far they end up from where they started).
  • Their total distance travelled is d = int_{t_1}^{t_2} |v(t)| dt = 10 + |-4| = 14 m (what a pedometer on their shoe records).

Two classic kinematics traps to avoid:
1. Forgetting to check v(t) = 0 when finding total distance on Paper 1: Before integrating v(t) from t_1 to t_2 to find distance, always solve v(t) = 0 first! If v(t) changes sign at t = c inside (t_1, t_2), you must split the integral at t = c and add the absolute values: d = |int_{t_1}^c v(t) dt| + |int_c^{t_2} v(t) dt|.
2. Thinking a(t) < 0 always means slowing down: A particle is speeding up whenever velocity v(t) and acceleration a(t) have the same sign (v(t) * a(t) > 0, either both positive or both negative!), and slowing down whenever v(t) and a(t) have opposite signs (v(t) * a(t) < 0).

Finding displacement and total distance when a particle reverses direction

A particle moves along a straight line so that its velocity v m s-1 at time t seconds (t >= 0) is given by v(t) = 3t^2 - 12t + 9. Initially, the particle is at the origin O.
(a) Find the times when the particle is momentarily at rest. [2 marks]
(b) Find the displacement of the particle from O at t = 4 s, and find the total distance travelled by the particle in the first 4 seconds. [5 marks]

  1. A particle is at rest when its velocity is zero. Factor out 3 first.

    3t2 − 12t + 9 = 3(t − 1)(t − 3) = 0 ⇒ t = 1 s and t = 3 s [M1 A1]

  2. Antidifferentiating v(t) gives the position s(t) at any time t, making both displacement and piecewise distance fast to compute.

    s(t) = ∫ (3t2 − 12t + 9) dt = t3 − 6t2 + 9t + C;   s(0) = 0 ⇒ C = 0 [M1]
    Displacement at t = 4:   s(4) = 43 − 6(42) + 9(4) = 64 − 96 + 36 = 4 m [A1]

  3. Evaluate s(0) = 0, s(1) = 4, s(3) = 0, and s(4) = 4, then add the distance of each leg.

    s(0) = 0,   s(1) = 1 − 6 + 9 = 4,   s(3) = 27 − 54 + 27 = 0,   s(4) = 4 [M1]
    Total distance d = |s(1) − s(0)| + |s(3) − s(1)| + |s(4) − s(3)| = 4 + 4 + 4 = 12 m [M1 A1]

(a) t = 1 s and t = 3 s; (b) displacement 4 m, total distance 12 m.

A particle moves along a line with velocity v(t) = 2t - 4 m s-1 for 0 <= t <= 5. Calculate the total distance travelled (in m) by the particle between t = 0 and t = 5.

  1. First find when v(t) = 0: 2t - 4 = 0 => t = 2 s.
  2. Split the integral at t = 2: d = |int_0^2 (2t - 4) dt| + |int_2^5 (2t - 4) dt|.
∫02 (2t − 4) dt = [t2 − 4t]02 = −4;    ∫25 (2t − 4) dt = [t2 − 4t]25 = 5 − (−4) = 9
Total distance = |−4| + 9 = 13 m
