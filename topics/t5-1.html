Differentiation, curve analysis and optimization

Guiding questionHow do the first and second derivatives reveal the exact gradient, turning points, concavity, and optimal values of a function?

What you need to be able to do

  • Interpret the derivative f'(x) as the gradient of the tangent line and the instantaneous rate of change of y = f(x).
  • Differentiate powers x^n (n rational) and standard functions sin x, cos x, e^x, and ln x.
  • Find equations of tangents and normals at a given point and find where they intersect axes or curves.
  • Differentiate composite, product, and quotient functions using the chain rule, product rule, and quotient rule.
  • Find intervals where f(x) is increasing or decreasing, classify local maxima and minima using f'(x) or f''(x), and identify stationary and non-stationary points of inflexion.
  • Connect features across the graphs of f(x), f'(x), and f''(x).
  • Set up a single-variable objective function using a constraint equation and find maximum or minimum values in context.

SL 5.1, 5.3, 5.4, 5.6

Limits, standard derivatives, tangents, normals and differentiation rules

Before you start: the chain rule differentiates composite functions, which you need from 2.1 Lines, functions, domains, inverses and composites. The derivatives of sin x and cos x hold only in radians, from 3.1 3D geometry, triangle trigonometry and radians, and you need the laws of exponents and logarithms from 1.2 Exponents, logarithms and the binomial theorem.

When we zoom in closely on a smooth curve y = f(x) near a point P(x, f(x)), the curve looks like a straight line. If we pick a nearby point Q(x + h, f(x + h)), the chord PQ has gradient (f(x + h) - f(x)) / h. As the step h -> 0, the chord approaches the tangent line, and its limiting gradient is the derivative f'(x) (also written dy/dx).

Power rule and standard derivatives

For any rational power n, the power rule brings the exponent down to the front and subtracts 1 from the exponent. Before differentiating roots or fractions with x in the denominator, always rewrite them in index form a x^n first:

  • 1 / x^k = x^{-k} (for example, 1 / x^3 = x^{-3} -> -3x^{-4} = -3 / x^4).
  • sqrt(x) = x^{1/2} -> (1/2)x^{-1/2} = 1 / (2 sqrt(x)), and 1 / sqrt(x) = x^{-1/2} -> -(1/2)x^{-3/2}.
  • A standalone constant c has gradient zero (d/dx (c) = 0), and constants multiplying a function stay in front: d/dx [k f(x)] = k f'(x).

In your formula booklet (SL 5.3 & 5.6): Standard derivatives given in the booklet:

  • f(x) = x^n => f'(x) = n x^{n-1}
  • f(x) = sin x => f'(x) = cos x and f(x) = cos x => f'(x) = -sin x
  • f(x) = e^x => f'(x) = e^x and f(x) = ln x => f'(x) = 1/x

Common mistake — Degrees vs radians and expanding before differentiating:
1. The formulas d/dx (sin x) = cos x and d/dx (cos x) = -sin x are valid only when x is in radians.
2. When given a single-term denominator like y = (x^3 - 4x + 1) / x^2, do not jump straight to the quotient rule! Split the fraction into powers first: y = x - 4x^{-1} + x^{-2}, then differentiate term by term in one line: dy/dx = 1 + 4x^{-2} - 2x^{-3}.

Tangents and normals

At the point on y = f(x) where x = a, the y-coordinate is y_1 = f(a) and the tangent gradient is m_T = f'(a). The normal line is perpendicular to the tangent at (a, f(a)), so its gradient is the negative reciprocal m_N = -1 / m_T = -1 / f'(a) (provided f'(a) != 0).

Chain rule, product rule, and quotient rule

When functions are combined by composition, multiplication, or division, you cannot simply differentiate each piece separately. Use the three structural rules from your Formula Booklet:

Differentiation rules for composite, product and quotient functions (SL 5.6)
Rule When to use it Formula Booklet form & fast pattern Quick example
Chain rule A function inside another function: y = f(g(x)). dy/dx = (dy/du) * (du/dx) = f'(g(x)) * g'(x)
(“Differentiate the outside leaving the inside alone, then multiply by the derivative of the inside.”)		 d/dx [e^{3x^2}] = e^{3x^2} * 6x
d/dx [ln(5x - 2)] = 5 / (5x - 2)
d/dx [cos(4x)] = -4 sin(4x)
Product rule Two functions of x multiplied together: y = u(x) v(x). dy/dx = u (dv/dx) + v (du/dx) = u v' + v u'
(“First times derivative of second, plus second times derivative of first.”)		 y = x^2 e^{3x}:
y' = x^2 (3e^{3x}) + e^{3x}(2x) = x e^{3x}(3x + 2)
Quotient rule One function of x divided by another: y = u(x) / v(x). dy/dx = (v (du/dx) - u (dv/dx)) / v^2 = (v u' - u v') / v^2
(“Bottom times derivative of top, minus top times derivative of bottom, all over bottom squared.”)		 y = (ln x) / x:
y' = (x(1/x) - (ln x)(1)) / x^2 = (1 - ln x) / x^2

Exam tip — Factoring after the product or quotient rule: Whenever a question asks you to solve f'(x) = 0 after using the product or quotient rule, do not expand brackets! Instead, factor out common terms (especially e^{kx}, which is never zero, or fractional powers like (2x + 1)^{-1/2}). For a quotient (v u' - u v') / v^2 = 0, you only need to set the numerator v u' - u v' = 0 (checking that v != 0).

Finding where a normal line intersects a coordinate axis

Consider the curve f(x) = e^{2x - 2} * (x^2 + 1). The normal to the curve at the point P where x = 1 intersects the x-axis at point Q. Find the exact coordinates of Q. [6 marks]

  1. Substitute x = 1 into f(x) first so we have the full coordinates of the point of contact P.

    f(1) = e2(1)−2(12 + 1) = e0(2) = 2 ⇒ P(1, 2) [A1]

  2. f(x) is a product of u = e^{2x−2} (which needs the chain rule, u' = 2e^{2x−2}) and v = x² + 1 (v' = 2x).

    f'(x) = e2x−2(2x) + (x2 + 1)(2e2x−2) [M1 A1]

  3. Substitute x = 1 into f'(x) to get m_T, then take the negative reciprocal for the normal.

    mT = f'(1) = e0(2) + (2)(2e0) = 2 + 4 = 6 [A1]
    mN = −16 [M1]

  4. Use point-gradient form at P(1, 2), then substitute y = 0 where the normal crosses the x-axis.

    y − 2 = −16(x − 1)
    0 − 2 = −16(x − 1) ⇒ x − 1 = 12 ⇒ x = 13 ⇒ Q(13, 0) [A1]

Q(13, 0)

Let f(x) = x^3 - 6x + 4. Calculate the gradient f'(1) of the tangent to the curve at x = 1.

  1. Differentiate term by term using the power rule: f'(x) = 3x^2 - 6.
  2. Substitute x = 1 into f'(x) = 3(1)^2 - 6.
f'(x) = 3x2 − 6 ⇒ f'(1) = 3(1)2 − 6 = −3

Increasing and decreasing functions, concavity, and connecting f, f' and f''

The first derivative f'(x) tells you the direction of the curve (going uphill or downhill), while the second derivative f''(x) = d^2y / dx^2 tells you the rate of change of the gradient itself—that is, how the curve bends (concavity).

Classifying stationary points and points of inflexion

  • Stationary points (f'(a) = 0): The tangent is horizontal. There are three possibilities:
    1. Local maximum: f'(x) changes sign from + to - across x = a (or f''(a) < 0, concave down).
    2. Local minimum: f'(x) changes sign from - to + across x = a (or f''(a) > 0, concave up).
    3. Stationary (horizontal) point of inflexion: f'(x) has the same sign on both sides of x = a (either + to 0 to +, like y = x^3, or - to 0 to -). Here f''(a) = 0 and f''(x) changes sign.
  • General point of inflexion: Any point where the curve switches between concave up (f''(x) > 0) and concave down (f''(x) < 0). A point of inflexion can be stationary (f'(a) = 0) or non-stationary (f'(a) != 0; here the gradient f'(x) itself has a local maximum or minimum).

Crucial trap — f''(a) = 0 does NOT guarantee a point of inflexion!
Consider f(x) = x^4 at x = 0: we have f'(x) = 4x^3 = 0 and f''(x) = 12x^2 = 0 at x = 0. However, for both x < 0 and x > 0, f''(x) = 12x^2 > 0 (concave up on both sides!), so (0, 0) is a local minimum, not a point of inflexion. Whenever the Second Derivative Test gives f''(a) = 0, the test is inconclusive—you must check a sign table of f'(x) or f''(x) on either side of x = a.

Classifying stationary and inflexion points of a polynomial

Consider f(x) = x^4 - 4x^3 + 10. Find the coordinates of all stationary points and points of inflexion on the graph of f, justifying their nature. [7 marks]

  1. Factor out the highest common power of x to find all roots of f'(x) = 0 cleanly.

    f'(x) = 4x3 − 12x2 = 4x2(x − 3) = 0 ⇒ x = 0 or x = 3 [M1 A1]
    f(0) = 10 ⇒ (0, 10);    f(3) = 81 − 108 + 10 = −17 ⇒ (3, −17) [A1]

  2. Differentiate f'(x) to get f''(x) and factor to find where concavity can change.

    f''(x) = 12x2 − 24x = 12x(x − 2) = 0 ⇒ x = 0 or x = 2 [M1 A1]

  3. For x < 0 (e.g. x = −1), f''(−1) = +36 > 0. For 0 < x < 2 (e.g. x = 1), f''(1) = −12 < 0. For x > 2 (e.g. x = 3), f''(3) = +36 > 0.

    At x = 3: f'(3) = 0 and f''(3) = 36 > 0 ⇒ (3, −17) is a local minimum [R1]
    At x = 0: f'(0) = 0, f''(0) = 0, and f''(x) changes sign (+ to −) ⇒ (0, 10) is a stationary point of inflexion
    At x = 2: f(2) = 16 − 32 + 10 = −6, f''(2) = 0, and f''(x) changes sign (− to +) ⇒ (2, −6) is a non-stationary point of inflexion [A1]

Local minimum at (3, -17); stationary point of inflexion at (0, 10); non-stationary point of inflexion at (2, -6).

For the cubic curve g(x) = x^3 - 6x^2 + 9x - 5, calculate the y-coordinate of its point of inflexion.

  1. Differentiate twice: g'(x) = 3x^2 - 12x + 9 and g''(x) = 6x - 12.
  2. Set g''(x) = 0 to get x = 2 (where g''(x) changes sign from negative to positive), then substitute x = 2 into g(x) = 2^3 - 6(2^2) + 9(2) - 5.
g''(x) = 6x − 12 = 0 ⇒ x = 2
g(2) = 8 − 24 + 18 − 5 = −3

Optimization in geometric and real-world contexts

Optimization problems ask for the largest or smallest possible value of a quantity (such as volume, surface area, profit, or travel time) subject to a fixed constraint. Every IB optimization question follows a reliable four-step structure:

  1. Use the constraint to eliminate the second variable: Write the constraint equation (for example, fixed volume V = pi r^2 h = 500), isolate the second variable (h = 500 / (pi r^2)), and substitute it into the quantity you want to optimize so that your objective function has only one input variable.
  2. Differentiate and set the derivative to zero: Rewrite fractions with negative exponents first (r^{-1} or r^{-2}), differentiate with respect to your variable, and solve f'(x) = 0.
  3. Justify that you found a maximum or minimum: The markscheme nearly always awards a dedicated mark for proving that your stationary point is indeed a maximum (f''(x) < 0) or a minimum (f''(x) > 0).
  4. Check domain endpoints and answer the exact question: If x is restricted to a closed interval a <= x <= b, compare f(x) at the stationary point with the endpoint values f(a) and f(b). Finally, check whether the question asked for the optimal dimension x or the optimal value f(x)!

Not needed for IB (Scope boundary): Multivariable optimization using partial derivatives (∂f/∂x = 0, ∂f/∂y = 0) or Lagrange multipliers is not in the IB Math AA syllabus. Every optimization problem in IB Math AA reduces to a function of a single variable after substituting the constraint.

Minimizing the surface area of an open-top rectangular box

An open-top rectangular container has a square base of side length x cm, height h cm, and a fixed volume of 108 cm3.
(a) Show that the total external surface area A cm2 of the container is given by A(x) = x^2 + 432 / x. [2 marks]
(b) Find the value of x that minimizes the surface area, justifying that it is a minimum, and state the minimum surface area. [5 marks]

  1. An open-top box has 1 square base of area x² and 4 vertical rectangular sides each of area xh. In a 'Show that' question, explicitly show the substitution of h.

    V = x2h = 108 ⇒ h = 108x2 [M1]
    A = x2 + 4xh [A1]
    A = x2 + 4x108x2 = x2 + 432x [AG]

  2. Rewrite 432/x as 432x⁻¹ before differentiating, then set A'(x) = 0.

    A'(x) = 2x − 432x2 = 0 [M1 A1]
    2x3 = 432 ⇒ x3 = 216 ⇒ x = 6 cm [A1]

  3. Show A''(6) > 0 to prove it is a minimum, then substitute x = 6 into A(x).

    A''(x) = 2 + 864x3 ⇒ A''(6) = 2 + 4 = 6 > 0, so x = 6 gives a minimum [R1]
    Amin = 62 + 4326 = 36 + 72 = 108 cm2 [A1]

x = 6 cm; minimum surface area A = 108 cm2.

A rectangle has one side along the positive x-axis, one side along the positive y-axis, and its opposite vertex (x, y) on the parabola y = 24 - 2x^2 in the first quadrant (0 < x < sqrt(12)). Calculate the maximum possible area of the rectangle.

  1. Write the area function A(x) = x y = x(24 - 2x^2) = 24x - 2x^3 and differentiate: A'(x) = 24 - 6x^2.
  2. Set A'(x) = 0 with x > 0 to get x = 2, then evaluate A(2) = 2(24 - 2(4)).
A(x) = x(24 − 2x2) = 24x − 2x3
A'(x) = 24 − 6x2 = 0 ⇒ x = 2 (since x > 0), and A''(2) = −24 < 0
Amax = 2(24 − 2(4)) = 32
