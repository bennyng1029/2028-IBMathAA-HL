Differential equations and Maclaurin series

Guiding questionHow can a rule that specifies only the local rate of change reconstruct an entire function—either exactly, numerically step-by-step, or as an infinite power series?

What you need to be able to do

  • Approximate solutions of dy/dx = f(x, y) numerically using Euler’s method y_{n+1} = y_n + h f(x_n, y_n), x_{n+1} = x_n + h, and use concavity to explain whether an Euler estimate is too high or too low.
  • Solve first-order separable differential equations dy/dx = g(x) h(y) by integrating int (1/h(y)) dy = int g(x) dx, including exponential, cooling, and logistic growth models.
  • Solve first-order homogeneous differential equations dy/dx = F(y/x) using the substitution y = vx and dy/dx = v + x (dv/dx).
  • Solve first-order linear differential equations dy/dx + P(x)y = Q(x) using the integrating factor I(x) = e^{int P(x) dx}.
  • Find Maclaurin series using f(x) = f(0) + x f'(0) + (x^2/2!) f''(0) + ... and by substituting, multiplying, differentiating, or integrating the standard Formula Booklet series (e^x, sin x, cos x, arctan x, ln(1 + x), (1 + x)^p).
  • Develop the Maclaurin series of a solution y(x) directly from a differential equation dy/dx = f(x, y) and initial condition y(0) = y_0 by repeated implicit differentiation.

Question decoder: The 4-way first-order DE classifier & Maclaurin series

Every first-order DE question in IB Math AA HL is handled by one of four methods: three exact (separable, homogeneous, integrating factor) and one numerical (Euler’s method). Run through the 4-way classifier below in order, then check the Maclaurin series decoder for power-series questions.

AHL 5.18

Euler’s method and separable differential equations

A first-order differential equation dy/dx = f(x, y) assigns a tangent gradient to every point (x, y) in the plane. Plotting short line segments with slope f(x, y) on a grid produces a slope field (direction field). Any solution curve y(x) passing through an initial point (x_0, y_0) must be tangent to the slope-field segments everywhere along its path. Slope fields are not in the AA guide (they belong to Applications and Interpretation HL); they are shown here only to picture what Euler’s method does.

Numerical approximation via Euler’s method

When a differential equation cannot be solved algebraically, Euler’s method approximates the solution curve by stepping forward along the current tangent line in small increments of step length h:

xn+1 = xn + h, yn+1 = yn + h × f(xn, yn)
h
constant horizontal step size
f(xn, yn)
gradient dy/dx evaluated at the current point (xn, yn)

Overestimate vs underestimate (concavity analysis): Because Euler’s method follows the tangent line at each step:

  • If the solution curve is concave up (d^2y/dx^2 > 0) on the interval, every tangent line lies below the curve, so Euler’s method gives an underestimate.
  • If the solution curve is concave down (d^2y/dx^2 < 0), every tangent line lies above the curve, so Euler’s method gives an overestimate.
  • Reducing the step size h (for example, halving h) reduces the truncation error and brings the Euler polygon closer to the exact curve.

Separable differential equations and growth models

When dy/dx = g(x) h(y), separate the variables by placing all y terms with dy and all x terms with dx:

int (1 / h(y)) dy = int g(x) dx.

Two classic scientific models in IB AA HL rely on separation of variables:

  • Newton’s law of cooling / radioactive decay: dT/dt = -k(T - T_s) => int 1/(T - T_s) dT = int -k dt => T(t) = T_s + A e^{-kt}.
  • Logistic population growth: dP/dt = kP(M - P), where M is the carrying capacity. Separating gives int M/(P(M - P)) dP = int Mk dt; splitting the left side by partial fractions 1/P + 1/(M - P) yields ln|P / (M - P)| = Mkt + C => P(t) = M / (1 + A e^{-Mkt}).

Using Euler’s method and solving a separable differential equation

Consider the differential equation dy/dx = 2xy^2 with initial condition y(0) = 1.

(a) Use Euler’s method with step size h = 0.2 to approximate y(0.4). [3 marks]

(b) Solve the differential equation analytically to find the exact value of y(0.4), and explain why Euler’s method underestimated the exact value. [5 marks]

  1. Apply y_{n+1} = y_n + 0.2(2 x_n y_n²) twice in a clear table.

    Step 0 → 1: x0 = 0, y0 = 1, f(0, 1) = 2(0)(1)2 = 0 ⇒ x1 = 0.2, y1 = 1 + 0.2(0) = 1 [M1 A1]
    Step 1 → 2: x1 = 0.2, y1 = 1, f(0.2, 1) = 2(0.2)(1)2 = 0.4 ⇒ x2 = 0.4, y2 = 1 + 0.2(0.4) = 1.08 [A1]

  2. Divide by y² to isolate y on the left and x on the right.

    ∫ y−2 dy = ∫ 2x dx ⇒ −1y = x2 + C [M1 A1]

  3. Substitute x = 0, y = 1 to find C, then compute y(0.4).

    At (0, 1): −1 = 0 + C ⇒ C = −1 ⇒ y(x) = 11 − x2 [A1]
    Exact value: y(0.4) = 11 − 0.16 = 10.84 = 2521 ≈ 1.19. Because y(x) is concave up (y″ > 0) on [0, 0.4], the tangent lines lie below the curve, so Euler’s method underestimates y(0.4). [A1 R1]

(a) 1.08; (b) 25/21 ≈ 1.19 (underestimate since curve is concave up)

Given the differential equation dy/dx = x + y with initial condition y(0) = 1, use Euler’s method with step length h = 0.1 to calculate the approximation y_2 for y(0.2).

  1. For the first step (x_0 = 0, y_0 = 1): f(0, 1) = 0 + 1 = 1, so y_1 = 1 + 0.1(1) = 1.1 at x_1 = 0.1.
  2. For the second step (x_1 = 0.1, y_1 = 1.1): f(0.1, 1.1) = 0.1 + 1.1 = 1.2, so y_2 = 1.1 + 0.1(1.2).
y1 = 1 + 0.1(0 + 1) = 1.1
y2 = 1.1 + 0.1(0.1 + 1.1) = 1.1 + 0.12 = 1.22

Homogeneous differential equations and the integrating factor

1. Homogeneous differential equations (y = vx)

A first-order differential equation is homogeneous if it can be written as dy/dx = F(y/x)—for example, dy/dx = (x^2 + 3y^2)/(2xy) = (1/2)(x/y) + (3/2)(y/x). Because the ratio y/x couples the variables, we introduce the new variable v = y/x:

Let y = vx ⇒ dydx = v + x dvdx ⇒ x dvdx = F(v) − v
v = y/x
dimensionless ratio substitution (must be memorized—not in the Formula Booklet!)
x(dv/dx) = F(v) − v
always separates into ∫ 1/(F(v) − v) dv = ∫ (1/x) dx

2. First-order linear differential equations and the integrating factor

When a differential equation is linear in both dy/dx and y, first divide by any coefficient in front of dy/dx to put it into standard form:

dy/dx + P(x) y = Q(x).

Multiplying every term by the integrating factor I(x) = e^{int P(x) dx} turns the left-hand side into a single product-rule derivative:

I(x) = e∫ P(x) dx ⇒ ddx [I(x) y] = I(x) Q(x) ⇒ I(x) y = ∫ I(x) Q(x) dx + C
P(x)
coefficient of y (including its plus or minus sign!) after making the coefficient of dy/dx equal to 1

Two classic integrating-factor traps:

  1. Forgetting to divide by the leading coefficient first: In x(dy/dx) - 2y = x^4, you must divide by x to get dy/dx - (2/x)y = x^3. Thus P(x) = -2/x, and I(x) = e^{int (-2/x) dx} = e^{-2 ln x} = e^{ln(x^{-2})} = x^{-2} (not e^{-2x}!).
  2. Forgetting to divide the constant + C by I(x): Write + C immediately when integrating int I(x) Q(x) dx, then divide the entire right-hand side (including C) by I(x).

Solving a first-order linear differential equation using an integrating factor

Find the particular solution of the differential equation x (dy/dx) + 2y = 4x^2 (x > 0) given that y(1) = 3. [6 marks]

  1. The integrating factor formula requires the coefficient of dy/dx to be 1.

    dydx + 2xy = 4x (so P(x) = 2x, Q(x) = 4x) [M1]

  2. Use exponent and log rules to simplify e^{2 ln x} to x².

    I(x) = e∫ (2/x) dx = e2 ln x = eln(x2) = x2 [M1 A1]

  3. The left side collapses to d/dx(x²y). Integrate the right side and don’t forget + C.

    ddx(x2y) = 4x3 ⇒ x2y = ∫ 4x3 dx = x4 + C [M1 A1]
    Substitute x = 1, y = 3: (1)2(3) = 14 + C ⇒ C = 2 ⇒ y = x2 + 2x2 [A1]

y = x² + 2 / x²

Solve the differential equation x (dy/dx) - y = 3x^2 (x > 0) given that y(1) = 2, and find the exact value of y(2).

  1. Divide by x: dy/dx - (1/x)y = 3x. The integrating factor is I(x) = e^{int (-1/x) dx} = e^{-ln x} = 1/x.
  2. Multiply by 1/x: d/dx(y / x) = 3 => y / x = 3x + C. Use y(1) = 2 to find C, then evaluate y(2).
ddx(yx) = 3 ⇒ yx = 3x + C
At (1, 2): 2 = 3(1) + C ⇒ C = −1 ⇒ y = 3x2 − x ⇒ y(2) = 3(4) − 2 = 10

Maclaurin series expansions and differential equation series

A Maclaurin series approximates a smooth function f(x) near x = 0 using a polynomial whose derivatives at x = 0 match those of f(x) order by order:

f(x) = f(0) + x f′(0) + x22! f″(0) + x33! f‴(0) + … + xnn! f(n)(0) + …
f(n)(0)
n-th derivative of f evaluated at x = 0
n!
factorial 1 × 2 × … × n (with 0! = 1)

Standard Maclaurin expansions in your Formula Booklet (Section 5.19 & 1.10):

  • e^x = 1 + x + x^2/2! + x^3/3! + ... (valid for all x in R)
  • sin x = x - x^3/3! + x^5/5! - ... (odd powers, alternating signs, all x in R)
  • cos x = 1 - x^2/2! + x^4/4! - ... (even powers, alternating signs, all x in R)
  • ln(1 + x) = x - x^2/2 + x^3/3 - x^4/4 + ... (divides by n, not n!; valid for -1 < x <= 1)
  • arctan x = x - x^3/3 + x^5/5 - ... (odd powers divided by 2k + 1, not factorials; valid for |x| <= 1)
  • (1 + x)^p = 1 + px + p(p - 1)/2! x^2 + ... (from Section 1.10; valid for |x| < 1)

Combining series and developing Maclaurin series from differential equations

You can generate new Maclaurin series in four fast ways:

  1. Substitution: Replace x with -x^2 in e^x to get e^{-x^2} = 1 - x^2 + x^4/2! - x^6/3! + ... immediately.
  2. Multiplication: Multiply the truncated polynomials for f(x) and g(x) and collect like powers of x up to the required degree.
  3. Term-by-term differentiation or integration: Differentiating sin x gives cos x; integrating 1/(1 + x^2) = 1 - x^2 + x^4 - ... gives arctan x = x - x^3/3 + x^5/5 - ....
  4. Implicit differentiation of a differential equation (Paper 3 favourite!): Given dy/dx = f(x, y) and y(0) = y_0, evaluate y'(0) = f(0, y_0) directly from the DE, then differentiate the DE implicitly using the product and chain rules to find y''(0), y'''(0), and so on.

Not needed for IB Math AA HL:

  • Second-order differential equations (a y'' + b y' + c y = f(x)), characteristic auxiliary equations, and coupled linear systems (dx/dt = ax + by) are not in the IB Math AA HL syllabus.
  • General Taylor series centred at x = a != 0, formal ratio/root tests for radius of convergence, and the Lagrange error remainder bound are not required in IB Math AA HL (only Maclaurin series centred at x = 0 are examined).

Finding a Maclaurin series directly from a non-linear differential equation

Let y = f(x) be the solution to the differential equation dy/dx = x + y^2 with initial condition y(0) = 1. Find the Maclaurin series for y up to and including the term in x^3. [6 marks]

  1. Substitute x = 0 and y(0) = 1 into dy/dx = x + y².

    y(0) = 1, and y′(0) = 0 + (1)2 = 1 [A1]

  2. Use the chain rule d/dx(y²) = 2y y′, and then the product rule on 2y y′.

    y″ = 1 + 2y y′ ⇒ y″(0) = 1 + 2(1)(1) = 3 [M1 A1]
    y‴ = 2(y′)2 + 2y y″ ⇒ y‴(0) = 2(1)2 + 2(1)(3) = 8 [M1 A1]

  3. Divide by 2! = 2 and 3! = 6 and simplify the fractions.

    y(x) = y(0) + x y′(0) + x22! y″(0) + x33! y‴(0) + … = 1 + x + 32x2 + 43x3 + … [A1]

1 + x + (3/2)x² + (4/3)x³ + …

In the Maclaurin series expansion of f(x) = e^{2x} cos(3x), find the exact coefficient of x^2.

  1. Write out the Booklet expansions up to x^2: e^{2x} = 1 + 2x + (2x)^2/2! + ... = 1 + 2x + 2x^2 + ... and cos(3x) = 1 - (3x)^2/2! + ... = 1 - (9/2)x^2 + ....
  2. Multiply (1 + 2x + 2x^2)(1 - (9/2)x^2) and collect the x^2 terms: 1(-9/2) + 2(1).
e2x cos(3x) = (1 + 2x + 2x2 + …)(1 − 92x2 + …)
Coefficient of x2 = 2 − 92 = −52 = −2.5
