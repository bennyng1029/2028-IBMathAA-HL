# t3-3 accuracy audit, wave 2 (AHL 3.12–3.18: vectors, lines, planes)

I checked all 59 questions (q001–q059). Every answer was recomputed from the stem with numpy/sympy/scipy in `audit2/t3-3.py`, without trusting the writer's `verify/t3-3.py`. The script covers:
- dot and cross products
- line–line classification (parallel / intersecting / skew) and intersection points
- line–plane and plane–plane intersections, and three-plane rank conditions
- acute angles between lines, line–plane angles (sine with the normal) and plane–plane angles (acute, between normals)
- point–plane, point–line and skew-line distances
- closest approach, using the correct time origin for the delayed start in q049 (minimised over t >= 20, then cross-checked with scipy)
- symbolic proofs: q023, q030 and q056(d)

For the MCQs it checks that exactly one option is correct. For short items it checks every quoted result.

**Result:** 0 MISMATCH after fixes. Before the fixes there was 1 MISMATCH (q052).

**LaTeX backslashes:** all `\\mathbf`, `\\cdot`, `\\times`, `\\mathbb` in `data/questions-t3-3.js` are double backslashes. A regex scan found no single-backslash LaTeX in the data file or in the non-comment lines of the three overlays.
