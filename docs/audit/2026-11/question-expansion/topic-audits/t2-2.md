The numbers inside the solution text were also checked (other roots, and P(14)/P(15) and the population values at n = 11 and 12 used in the checks). The script also checks markscheme line counts against marks and that each challenge item's first hint starts with `Decode:`. The run ends with 0 MISMATCH lines.
