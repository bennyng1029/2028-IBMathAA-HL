## t5-3

### Major

**M1. Misconception note for distractor π/2 is mathematically false.** `data/questions-t5-3.js:307` (q013)
> `1: 'You forgot to multiply by the outer factor of pi in V = pi int y^2 dx, or integrated cos x instead of cos^2 x.'`

Neither error gives π/2. Forgetting the π gives ∫₀^{π/2} cos²x dx = π/4. Integrating cos x instead gives π∫cos x dx = π, which is option 3; the note for option 3 says this itself. π/2 comes from taking ∫₀^{π/2}cos²x dx as π/2 and dropping the outer π, or from using cos²x = 1 + cos 2x without the ½ and dropping the π.
Suggested: `'π/2 is not a volume of the form π × (something). Check that you used cos^2 x = (1 + cos 2x)/2, including the factor 1/2, and kept the outer π: V = π × (π/4) = π^2/4.'`

**M2. Partial fractions in integration is labelled AHL 5.16; the 2019 AA guide places it in AHL 5.15.** AHL 5.15 includes "Use of partial fractions to rearrange the integrand". AHL 5.16 covers substitution and parts only.
- `topics/t5-3.html:72`: `<strong>Partial fractions</strong> (AHL 1.11 + 5.16)` → `(AHL 1.11 + 5.15)`
- `data/questions-t5-3.js:256` (q011): `syllabus: 'AHL 5.16'` → `'AHL 5.15'`

**M3. "Such as …" input examples give away the exact answer.** The example input format shown to the student is the answer itself:
- `topics/t5-3.html:361` (Try-it): "…such as `pi/6`…". The answer is π/6.
- `topics/t5-3.html:428` (Try-it): "…such as `8*pi`…". The answer is 8π.
- `data/questions-t5-3.js:210` (q009): "…such as `(2*e^3+1)/9`…". The answer is (2e³+1)/9.
- `data/questions-t5-3.js:258` (q011): "…such as `2*ln(8/5)`…". The answer is 2 ln(8/5).
- `data/questions-t5-3.js:352` (q015): "…such as `(2*e^pi+1)/5`…". The answer is (2e^π+1)/5.

Suggested: use a neutral example that is not the answer, for example "such as `pi/3`", "`3*pi`", "`(e^2-1)/4`", "`3*ln(2)`", "`(e^pi-1)/2`".

### Minor

**m1.** `data/questions-t5-3.js:191` (q008): `answer: 4.3147632`. The exact value (4/3)(√5+1) is 4.3147573. The answer is accepted because it is within the 1% tolerance, but the stored value is wrong from the 6th significant figure. Use `4.3147573`.

**m2.** `topics/t5-3.html:132`, `data-def` of differentiable: "…if the derivative limit from the left equals the derivative limit from the right." This omits that the limit must be finite. Suggested: "…if the left and right limits of (f(a+h) − f(a))/h exist, are finite and are equal."

**m3.** `topics/t5-3.html:39`, checklist: "Differentiate and integrate reciprocal trig (tan x, sec x, cosec x, cot x)…". AHL 5.15 requires the indefinite integrals of the *derivatives* of these functions (for example ∫sec²x dx, ∫sec x tan x dx). It does not require ∫sec x dx or ∫cosec x dx. Suggested: "Differentiate tan x, sec x, cosec x, cot x, a^x, log_a x, arcsin x, arccos x, arctan x, and integrate their derivatives (e.g. ∫sec²x dx, ∫1/(1+x²) dx)."

**m4.** `topics/t5-3.html:61–62`: the row headed "Standard AHL booklet forms: … or tan x" lists `int tan x dx = -ln|cos x| + C`. ∫tan x dx is not in the Formula Booklet; it is found by log inspection. Suggested: move tan x into the "g′(x)/g(x)" row (row 2), or label it "(not in booklet, by inspection of −(−sin x)/cos x)".

**m5.** `topics/t5-3.html:396`: "often taught by AI tutors and US calculus textbooks". "AI tutors" is an odd and unprofessional aside. Suggested: "often taught in other calculus courses and textbooks".

**m6.** `assets/js/widgets-t5-3.js:237`: the readout label `'Exact integral V = π ∫ y² dx'` is also shown in washer mode, where the value is π∫(y₁² − y₂²)dx. Suggested: switch the label to `V = π ∫ (y_outer² − y_inner²) dx` when `m.fnInner` is set.

## t5-4

### Major

**M4. The Maclaurin widget states the wrong validity interval for ln(1+x).** `assets/js/widgets-t5-4.js:258`
> `{ value: 'ln1p', label: t('f(x) = ln(1 + x)  (|x| ≤ 1)') }`

|x| ≤ 1 includes x = −1, where ln(1+x) is undefined and the series diverges (−∑1/n). The correct interval is −1 < x ≤ 1, which the page itself states at `topics/t5-4.html:285`.
Suggested: `'f(x) = ln(1 + x)  (−1 < x ≤ 1)'`.

**M5. "Such as …" input examples give away the exact answer.** This is the same issue as M3:
- `data/questions-t5-4.js:120` (q005): "exact fraction like `-4/3`". The answer is −4/3.
- `data/questions-t5-4.js:275` (q012): "like `11/6`". The answer is 11/6.
- `data/questions-t5-4.js:347` (q015): "like `2/3`". The answer is 2/3.
- `data/questions-t5-4.js:367` (q016): "You can enter `2*sqrt(7)`". The answer is 2√7.

Suggested: neutral examples such as `-5/7` or `3*sqrt(2)`.

### Minor

**m7.** `topics/t5-4.html:310`, figcaption: "Notice that ln(1 + x) and (1 + x)^{-1} only converge inside |x| < 1". ln(1+x) also converges at x = 1, as line 285 says. Suggested: "…(1 + x)^{-1} converges only for |x| < 1 and ln(1 + x) only for −1 < x ≤ 1, because of the vertical asymptote at x = −1."

**m8.** `assets/js/widgets-t5-4.js:87–89, 95`. The readouts are fixed as "Steps to x = 1.5", "Euler estimate y_n(1.5)" and "Exact value y(1.5)". With `nSteps = Math.round(1.5/h)` the end point is actually x = 1.6 for h = 0.2 and 0.4, 1.4 for h = 0.35, and 1.35 for h = 0.45. The steps readout shows the true x, but the other two labels then contradict it. Suggested: build the labels from `actualTargetX`, or restrict h to divisors of 1.5 (0.05, 0.1, 0.15, 0.25, 0.3, 0.5).

**m9.** `topics/t5-4.html:66–67`: the homogeneous row writes `dy/dx = f(y/x)` and `x(dv/dx) = f(v) - v`. The rest of the page and the bank use `F(y/x)`, and `f` is already used for f(x, y). The row also refers to "every term in M(x, y) and N(x, y)", but M and N are never defined. Suggested: use `F` throughout and write "(numerator and denominator are polynomials whose terms all have the same total degree, e.g. (x^2 + y^2)/(xy))".

**m10.** `topics/t5-4.html:101`: "Expand a non-standard function such as tan x, sec x, or e^{sin x} from first principles". On this site "first principles" means the limit definition (AHL 5.12), so this is confusing. e^{sin x} is also more quickly done by substitution, as q017 does. Suggested: "…by repeated differentiation (using f^{(n)}(0))".

**m11.** `topics/t5-4.html:47`: "Every first-order differential equation in IB Math AA HL belongs to one of four exact archetypes". The fourth row is Euler's method, which is a numerical method and not a type of DE. Non-linear DEs such as dy/dx = x + y² (used on this page) fit none of the three analytic types. Suggested: "Every first-order DE question in IB Math AA HL is handled by one of four methods: three exact (separable, homogeneous, integrating factor) and one numerical (Euler)."
