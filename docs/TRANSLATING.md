# Translating Analysis Lab (IB Mathematics AA HL 2028)

The site is authored in plain, direct English. **Hong Kong Traditional Chinese (`zh-Hant`)**, **Japanese (`ja`)**, and **Korean (`ko`)** are **overlays**: separate files under `i18n/<lang>/` that map each English string to its translation. Nobody edits the English HTML pages to translate them, and any missing translation automatically falls back to English.

The student chooses the language manually in the header selector. **There is zero auto-detection**: the site always opens in English until the student chooses a language, and that choice is saved in `localStorage` (`s1.lang`).

---

## 1. How the Overlay System Works

```
i18n/<lang>/index.js        list of overlay files that exist (generated by tools/i18n-check.js)
i18n/<lang>/ui.js           shell and engine text: header, footer, quiz engine, practice filters, topic titles
i18n/<lang>/common.js       shared mathematical terms, unit words, and recurring widget labels
i18n/<lang>/home.js         index.html
i18n/<lang>/practice.js     practice.html
i18n/<lang>/t1-1.js         topics/t1-1.html: page text, attributes and widget strings (one per topic id)
i18n/<lang>/t1-1.q.js       data/questions-t1-1.js: the question bank of t1-1 (one per topic id)
```

### File Format

```js
// i18n/zh-Hant/t1-1.js
S1.i18n.register('zh-Hant', 't1-1', {
  strings: {
    "Arithmetic sequences and series": "等差數列與等差級數",
    "An <dfn>arithmetic sequence</dfn> has a constant difference between consecutive terms.": "<dfn>等差數列 <span class=\"en-term\">(arithmetic sequence)</span></dfn>相鄰兩項之間的差是一個常數。",
  }
});

// i18n/zh-Hant/t1-1.q.js
S1.i18n.register('zh-Hant', 't1-1.q', {
  questions: {
    "t1-1-q001": {
      stem: "<p>…</p>",
      options: ["…", "…", "…", "…"],
      hints: ["…"],
      solution: "<p>…</p>",
      misconception: { "0": "…", "2": "…", "3": "…" }
    }
  }
});
```

## 2. Keeping English Exam Wording Visible

Because the student will sit the IB Mathematics AA HL exam in **English**, key English terminology and markscheme phrasing stay visible alongside the translation:

1. **Key Terms (`<dfn>`)**: Every `<dfn>` shows the translated term followed by the English term inside `<span class="en-term">(English term)</span>`:
   - `zh-Hant`: `<dfn>數學歸納法 <span class="en-term">(mathematical induction)</span></dfn>`
   - `ja`: `<dfn>数学的帰納法 <span class="en-term">(mathematical induction)</span></dfn>`
   - `ko`: `<dfn>수학적 귀납법 <span class="en-term">(mathematical induction)</span></dfn>`
2. **Command Terms**: The first time an IB command term (*Show that*, *Hence*, *Find*, *Determine*, *Sketch*, *State*, *Prove*, *Verify*) matters in a question stem, keep the English in brackets:
   - `zh-Hant`: `證明 (Show that)`, `由此 (Hence)`
   - `ja`: `示しなさい (Show that)`, `これを用いて (Hence)`
   - `ko`: `보이시오 (Show that)`, `이를 이용하여 (Hence)`
3. **Exam Tips (`callout--exam`), Model Answers, and Markscheme Points (`M1`, `A1`, `R1`)**: Shown automatically in **both languages** (English first, translation underneath) so the student learns exact IB markscheme phrasing.
4. **Never Translated**: Mathematical symbols, variables ($x, y, z, u_n, S_n, \Delta, \lambda, \mu$), `.chem` formulas, `.unit` units, numbers, syllabus codes (`SL 1.2`, `AHL 5.18`), level tags (`SL`, `HL`, `AHL`), paper names (`Paper 1`, `Paper 2`, `Paper 3`), and mark codes (`M1`, `A1`, `R1`, `AG`).

## 3. Workflow & Verification Commands

1. **Extract strings for a topic page**:
   ```bash
   node tools/i18n-extract.js t1-1 --lang zh-Hant --write
   ```
2. **Check translations and regenerate `i18n/<lang>/index.js`**:
   ```bash
   node tools/i18n-check.js zh-Hant t1-1 --stats
   node tools/i18n-check.js ja --stats
   node tools/i18n-check.js ko --stats
   ```
   All checks must finish with **zero `LINT` errors** and **zero `STALE` keys**.

## 4. Official Regional Mathematics Terminology Standards

Always consult the language-specific glossaries before translating:
- **Hong Kong Traditional Chinese (`zh-Hant`)**: [`docs/glossary-zh-Hant.md`](glossary-zh-Hant.md) — Strictly follows the Hong Kong Education Bureau (EDB) 《中學數學科常用英漢辭彙》 (*An English-Chinese Glossary of Terms Commonly Used in the Teaching of Mathematics in Secondary Schools*) and HKDSE Mathematics (Compulsory Part + Extended Modules M1/M2). Uses Hong Kong standard written Chinese (書面語) and Hong Kong terms (e.g., 數列, 等差數列, 等比數列, 複數, 阿根圖, 棣美弗定理, 複合函數, 反函數, 漸近線, 弧度, 正弦定律, 餘弦定律, 純量積/點積, 向量積/叉積, 異面直線, 四分位數間距, 迴歸線, 隨機變數, 二項分佈, 正態分佈, 貝葉斯定理, 導數, 鏈式法則, 駐點, 拐點/轉向點, 定積分, 分部積分法, 旋轉體體積, 微分方程, 歐拉法, 積分因子, 麥克勞林級數, 有效數字).
- **Japanese (`ja`)**: [`docs/glossary-ja.md`](glossary-ja.md) — Strictly follows MEXT Upper Secondary School Mathematics (高等学校学習指導要領 数学I・A・II・B・III・C) terminology in polite です・ます style.
- **Korean (`ko`)**: [`docs/glossary-ko.md`](glossary-ko.md) — Strictly follows the Korean 2015/2022 Revised National Curriculum High School Mathematics (공통수학, 대수, 미적분, 확률과 통계, 기하) terminology in polite 해요체 style.
